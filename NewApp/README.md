# NewApp — the ground-up rebuild

Everything about the **new TradeAnalyzer application** (new exe, data-first, UI from day one) lives under this folder.
It is deliberately separate from the existing app's documentation:

| Folder | Belongs to |
|---|---|
| `NewApp/` | the **new** application — requirements, design, decisions |
| `Requirements/`, `docs/`, `.ai/`, `UserManual/`, `changelogs/` | the **existing** application (untouched, still the daily driver) |

Start at `NewApp/requirements/00-discovery-qa.md` — the discovery record (decisions D1–D7, questions Q1–Q21, all closed 2026-09-05).
Spec documents in `NewApp/requirements/`: `01-purpose-and-principles.md` (P1–P15, acceptance criteria) → `02-raw-domains-and-data-dictionary.md` (conventions, every table and column) → `03-quality-gate-and-exceptions.md` (check catalogue, exception lifecycle, status email) → `04-collector.md` (run pipeline, archive, one-shot jobs, hand-off) → `05-inspector-ui.md` (schema-driven inspector, bespoke views, exceptions workbench) → `06-repository-and-packaging.md` (workspace, versioning, build order B1–B10, definition of done). **All six at v1 (2026-09-05), review round 1 complete** — every carried open item and all 13 review findings closed; the only things still open are the † thresholds (03 §10) and the pre-pilot checklist (04 §11). **The E*Trade verify list closed on 2026-09-07** after the operator re-authorised — one live chain call, one quote and one portfolio call settled every open field question, and QC-410's delta tolerance was measured at 0.05. **That checklist was worked down on 2026-09-06 and is now as far as it can go without the operator.** Newly settled: the Finnhub free tier (estimates survive via the earnings calendar at 99 % universe coverage; short interest does not), and Polygon's share-count fallback (proven live at >= 95.8 %, no key needed). Newly *retired as unanswerable*: QC-301, QC-302 and QC-702 — the old app never stored the quantity, so those three † values now belong to the pilot like the rest. What is left needs the operator: **four items wait on one live E*Trade call**, blocked on a manual re-auth (`scripts/etrade-login.bat` — the token expired at midnight ET rather than going dormant, so renew cannot recover it); **one is a spend decision** (the IV bootstrap source, not needed until B7); and **one waits on build step B5**. One further source question now sits in 02 §12 rather than the checklist: short interest has no confirmed free provider. **Build steps B1 through B6 are complete** (06 §9): the workspace and the app shell, the schema-driven inspector, the collector and its archive, the quality gate and phases 0-4, `backfill_bars` and the exception review queue, and now the account, the chain subset and the chains with their Chains and Account views. Next is B7 — the phase-8 event domains, the IV bootstrap and the derivation phase; its one open decision is the bootstrap source, which is a spend decision for the operator.

Code for the new app will live in `packages/core` (shared, Electron-free) and `packages/next` (the new exe) when the paper work is done — see Q11.
