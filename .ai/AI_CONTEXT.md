## 1. What the app is

TradeAnalyzer is a **single-user Electron desktop app for a retail options/swing trader**. It screens the S&P 500 + Russell 1000 + ETF universe for sound trade candidates, runs five analysis modes, scores candidates with a configurable engine, produces a daily AI intelligence brief, models multi-leg option payoffs, tracks a portfolio synced from E*Trade, and surfaces earnings/news risk. No cloud sync, no multi-user, no broker order execution (E*Trade integration is read-only).

The app is **feature-complete against the v1 spec** (now consolidated in `Requirements/spec/` — start at `00-index.md`), including all five enhancement tracks, the News & Research module, the Agent overhaul, and the scoring engine. The remaining gate to v1.0.0 is a week of real-world usage validation. (Earlier scattered specs are archived in `Requirements/_legacy/`.)

### E*Trade auth quirks
- OAuth 1.0a flow in `etrade-auth.ts`; all calls go through `etradeGet()` which signs requests — never build auth headers by hand.
- Tokens expire at **midnight ET**; after 2h inactivity they go dormant (E*Trade → `oauth_problem=token_rejected`) → call `renewAccessToken()`. Batch jobs auto-renew and surface a "Reconnect" notification on hard expiry. **A dormant token doesn't reliably 401 — it can kill/hang the stream (undici `terminated`)**, so the daily-iv-update connectivity probe renews-and-retries on ANY failure, not just auth-shaped errors (v1.1.92; the old heuristic halted the evening chain 8 of 10 trading days in late June 2026). **The renew endpoint was the wrong path (`/v1/oauth/...`) until v1.1.99 — renewal always failed and dormant tokens never auto-revived until a manual re-auth; correct path is `/oauth/renew_access_token`.** `checkConnection()` (now `checkETradeConnection`) was a date-stamp check only; since v1.1.166 it returns `ok` free when the stamp is today's and otherwise **probes** rather than declaring `expired` (new `unknown` status for transient failures). v1.1.100 adds a **live** `testConnection()` (`etrade:test-connection` → real SPY quote + renew-and-retry, returns `ok|renewed|expired|error|no_token|no_credentials`; Settings has a Test Connection button + verifies on mount) and a **~90-min keep-alive heartbeat** (`probeETradeConnection` in `index.ts`) that pings E*Trade inside the 2h window so the token never goes dormant during a session. **v1.1.344:** an `expired` probe (keep-alive, or a once-a-day morning check in [07:30, 10:15) ET on trading days) emails a re-auth warning at most once per ET day (`etrade-token-alert.ts`). The collector host latches a token E*Trade has declared `token_expired` after a renew and sends no more E*Trade calls that run (`etrade-token-latch.ts`). `collector-watchdog` checks the previous trading day when run before 17:05 ET (`watchdogTargetDate`), so a manual chain past midnight no longer halts on "no run for today". **v1.1.345:** `data-collector` started before 09:30 ET records the previous session (`collectorTradingDate`), not the new calendar date.
- Credentials stored encrypted via `secure-settings.ts` (DPAPI on Windows).
- **E*Trade IV is a decimal fraction** (0.3882 = 38.82%). Multiply by 100 when ingesting into anything that stores/displays IV as a percentage. `OptionContract.iv` stays a decimal fraction in memory — Black-Scholes uses it directly as sigma.

## 4. Architecture

### Process model
- **Main** (`src/main/`) owns the SQLite connection, all provider calls, the rate limiter, the batch scheduler, and the Fastify API server. Exposes a typed IPC surface.
- **Preload** (`src/preload/index.ts`) uses `contextBridge` to expose `window.api.*` (34 namespaces) and `window.dialog.*`. `contextIsolation: true`, `nodeIntegration: false`.
- **Renderer** (`src/renderer/`) is React/Vite. Never touches Node/FS/network — only `window.api.*`.

### Data flow
```
React view → window.api.<ns>.<method>() → ipcRenderer.invoke(channel)
  → ipcMain.handle in src/main/ipc/ipc-*.ts → Service in src/main/services/
  → better-sqlite3 (via withTransaction) and/or DataProvider/OptionsProvider
```
IPC responses use a uniform `IpcResult<T>` = `{ ok: true, value } | { ok: false, error }`. The preload `invoke()` wrapper unwraps it and throws on `ok: false`.

### Rate limiting & batch pipeline
- `TokenBucketRateLimiter` (`rate-limiter.ts`) + SQLite-backed `JobQueue` (`job-queue.ts`) make long runs resumable/cancellable. All Polygon traffic must go through it — never ad-hoc `fetch`.
- `BatchService` (`batch-service.ts`) is the daily job scheduler. Jobs implement `BatchJobHandler` (`run(onProgress, signal, force?)`), are registered in `index.ts`, run one-at-a-time under a mutex (so same-time jobs chain), support `runOnStartup` / `startupDelaySeconds` / `dailyScheduleTime` / per-job `defaultConfig`, and stream progress to the Batch Jobs view. **A `schedule` trigger refused by the mutex logs and returns (v1.1.225)** — the 5-minute tick retries and the waiting job is usually also in the chain holding the lock, so notifying per tick produced ~30 identical warnings in one evening; `manual` / `startup` refusals still notify.

### Local API server
`ApiServer` (`api-server.ts`) runs Fastify on `127.0.0.1:7432` with token auth (`~/.tradeanalyzer/agent.token`). Route modules in `src/main/api/`. Used by the external TraderAgent to read briefs, run Strategy Lab, and call the Critic. `GET /analysis/snapshots/latest?mode=wheel` returns the newest snapshot of a mode including global (`watchlist_id NULL`) batch rows — scripts use it instead of opening the SQLite file (`fr-wheel-monthly-first-ab.mjs`).

## 9. Conventions (summary — full rules in /CLAUDE.md)

- TypeScript strict; no `any` (use `unknown` + guards). Functional React components only.
- All DB access via `withTransaction(db, fn)` — never `db.transaction(fn)()` directly.
- All market data via `DataProvider` / `OptionsProvider` — never ad-hoc `fetch` to a provider.
- Every derived financial metric carries a `// see docs/formulas.md#anchor` comment + a `docs/formulas.md` entry.
- IV stored/displayed as a percentage (38.82); E*Trade returns a decimal — `×100` on ingest.
- Monetary values USD, per share. DTE is calendar days.
- Conventional Commits. Every material change bumps version + updates `CHANGELOG.md` + `changelogs/v{version}_{date}.md` + this file, in one commit. Bug fixes ship a regression test. After committing, run `npm run package`.

## 10. Known quirks & gotchas

Six tickers, 343 rows each, on both sides of the IVolatility → E*Trade splice: every value is a percentage (SPY ~12.7, MRNA ~102). Divide by 100 before Black-Scholes. NewApp's `derived_iv30_daily` and IVolatility's `iv30` ARE decimals.
