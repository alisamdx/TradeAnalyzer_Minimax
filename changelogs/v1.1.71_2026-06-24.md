# v1.1.71 — 2026-06-24

## Retrospect In Progress — sticky Brief dropdown

### Problem
On the Retrospect screen's **In Progress** tab, the **Brief** date dropdown scrolled away with the
picks grid. To pick a different brief you had to scroll all the way back to the top, every time.

### Fix
The `.retro-brief-selector` bar is now `position: sticky; top: 0` within the scrolling
`.retro-content`, so it stays visible while the grid scrolls under it. Negative margins span the
container's 16px padding (top + sides) so table rows can't peek above or beside the bar, with the
padding restored inside; a bottom divider separates it from the grid. The background uses the
theme-aware `--bg` token, so it works in both dark and light themes.

CSS-only change (`src/renderer/src/styles.css`) — no logic, no data, no tests affected.
