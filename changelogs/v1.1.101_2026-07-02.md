# v1.1.101 — 2026-07-02

## "Wheel (Vetted)" filter template

### Why
The `wheel_opportunity` filter gates on **fundamentals only** (`calculateWheelSuitability ≥ 60` —
ROE, D/E, market cap, a constant stability baseline). Over S&P 500 + Russell 1000 that clears
~**792** names — basically every profitable large/mid-cap. It never looks at options: no
liquidity, no expiry, no real premium. The user asked to cut that to "only good candidates,
keeping liquidity and monthly expiry in mind." This is the filter-screen version of what the
Daily Brief does (score → validate the actual structure → hard liquidity gate), minus the LLM.

### What
A new **Wheel (Vetted)** template (Filters → Wheel category) that runs a two-stage funnel so the
expensive options work only touches names that already passed the cheap gate:

- **Tier 1 — fundamentals (no option call, every name):** wheel suitability ≥ 70. Rejections here
  cost nothing, so only genuine foundation candidates reach Tier 2.
- **Tier 2 — one monthly-expiry chain per survivor:** fetch the nearest standard **monthly**
  expiry (3rd Friday ≥ 25 DTE), target the **~0.30Δ put** (delta-closest; falls back to the ~OTM
  strike when deltas are missing), and require:
  - **open interest ≥ 100** on that put,
  - **bid/ask spread ≤ 15%** of mid,
  - **annualized CSP yield ≥ 8%** — the "real premium" floor (`(credit/strike) × 365/DTE`).
    Used instead of an IV-rank gate because `iv_history` only covers tracked names, so a
    universe-wide IV floor would reject almost everything; the live chain gives the true premium.

Result columns: Score · IV % · Put Strike · OI · Ann % (sorted by annualized yield, best first).
Each row's match reason spells out the exact put — expiry, DTE, Δ, credit, OI, spread. The
⭐ Save to Watchlist bulk action and the Payoff hand-off (pre-loads a CSP at the vetted strike)
both work with it. Price-agnostic per the design decision — last price is a sortable column so
sub-$50 names can be eyeballed, but price isn't gated.

### Design decisions (user-selected)
- **New template**, not a tightening of `wheel_opportunity` — the loose one stays for quick browsing.
- **No price cap** — vet on quality + premium + liquidity regardless of share price.
- **Balanced** thresholds (`WHEEL_VETTED_DEFAULTS`): suitability 70, target Δ 0.30, OI 100,
  spread 15%, annualized 8%. Tunable in one place.

### Cost / behavior note
This is a **deeper scan**: every Tier-1 survivor makes one options-chain call (rate-limited), so a
full S&P 500 + Russell 1000 run takes noticeably longer than the fundamentals-only template — a
deliberate "find me vetted wheels" action, not a browse. Over a watchlist it's fast. ETFs are
skipped (no fundamentals to vet). Requires the E*Trade options provider connected.

### Tests
`tests/wheel-vetted.test.ts` (+13) covers the pure gate logic: UTC 3rd-Friday math
(`thirdFridayOnOrAfter`), target-put selection (`pickWheelPut`, delta + OTM fallback + quote
requirement), annualized yield (`annualizedCspYield`), and the Tier-2 gate (`assessWheelPut` —
pass + thin-OI / wide-spread / low-premium fails).
