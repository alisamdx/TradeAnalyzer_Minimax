# v0.30.2 — 2026-06-07

## Trade Management Alerts — ENH-5

Collapsible "⚡ Trade Management" banner above the open positions table.
Computed client-side from already-loaded positions + E*Trade data — no new
IPC handlers, service methods, or DB migrations.

### Three alert types

| Alert | Rule | Data source |
|-------|------|-------------|
| ✓ Take Profits | `et.totalGainPct ≥ 50` | E*Trade sync |
| ⏱ Manage Now | `DTE ≤ 21` | `pos.expirationDate` |
| ⚠ Delta Drift | `abs(Δ) > 0.45` | `et.delta` or `pos.delta` |

### UX
- Amber left-border card with badge count; hidden when no alerts
- Each row shows: alert type · ticker · position type · strike · detail value
- "View →" expands the position's detail row and smooth-scrolls to it
  (`id="pos-row-{id}"` added to each TR for the scroll target)
- Collapse/expand toggle persists within the session
