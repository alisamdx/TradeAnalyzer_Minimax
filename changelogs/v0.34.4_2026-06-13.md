# v0.34.4 — 2026-06-13

## Fix: backtest silent flat-zero when capital < CSP collateral

A CSP/Wheel backtest on a high-priced stock (META ~$645 → ~$60k collateral) with the
default $25k starting capital never opened a position → flat equity curve, all-zero
metrics, no explanation.

runSimulation now tracks when an entry is skipped for insufficient capital and, if the
run produced zero trades, throws a clear error naming the collateral needed (or a
premium/data message otherwise) — surfaced in the Backtest view's error banner instead
of a misleading flat-zero result. The aggregate 💰 P&L backtest is per-trade ROC and
unaffected.

Test: high-priced stock + low capital → simulate throws /Starting Capital/. Suite 309
passing.
