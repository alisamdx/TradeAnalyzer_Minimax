# v1.1.115 — 2026-07-03

## Filters Prefill: only precompute the filters in regular use

Follow-up to v1.1.114. The `filters-prefill` batch job originally precomputed all 8 filter templates over Universe = All every evening. Several of those filters aren't used, and two of them (Wheel (Vetted), Assignment Risk) fetch a live option chain per surviving ticker — so precomputing the unused ones burned meaningful E*Trade time for nothing.

### Change

- The job now runs a **configurable template allowlist** instead of all templates.
- **Default allowlist** (`DEFAULT_PREFILL_TEMPLATES`): `rsi_oversold`, `iv_rank_high`, `price_alert`, `wheel_vetted`.
- **Skipped by default**: `rsi_overbought` (RSI Overbought), `iv_rank_low` (IV Low), `assignment_risk` (Assignment Risk), `wheel_opportunity` (Wheel Opportunity).
- The allowlist is stored in `batch_jobs.config_json.enabledTemplates` for the `filters-prefill` job, seeded from the default on first registration (and back-filled on upgrade from v1.1.114, whose row had no config). Edit that row to change which filters are precomputed — no rebuild needed.
- An **empty allowlist** makes the job return `skipped` cleanly (nothing scanned).
- Skipped filters aren't pre-populated in the Filters view (no match-count badge, no instant results) — clicking one still runs it live on demand exactly as before.

### Implementation

- `FiltersPrefillJob` constructor now also takes the `DbHandle`; `enabledTemplateIds()` reads/validates `config_json.enabledTemplates`, falling back to `DEFAULT_PREFILL_TEMPLATES`. The run loop filters `FILTER_TEMPLATES` to the enabled set (and short-circuits to `skipped` when empty).
- Registration in `index.ts` passes `db` and seeds `defaultConfig: { enabledTemplates: DEFAULT_PREFILL_TEMPLATES }`.

### Tests

- `tests/filters-prefill.test.ts` extended to 12: default allowlist runs exactly the four (and never the skipped heavy filters), explicit allowlist honored, empty allowlist → `skipped`. Existing behavior tests (failure isolation, all-fail, abort) now pass an all-enabled db stub.
