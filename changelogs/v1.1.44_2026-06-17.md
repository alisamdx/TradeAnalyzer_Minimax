# v1.1.44 — 2026-06-17

## Realized P&L wired into the full-sync close path

### The gap
The v1.1.42 full-sync reconcile marks a position closed when it disappears from the broker, but
left `realized_pnl` null — so a closed position (e.g. NVDA) showed in the Closed tab with a blank
Realized P&L. The exact figure lives in E*Trade transaction history (the separate "Sync Closed
Positions"), but that isn't always run, so the close path was incomplete on its own.

### The change
`closeMissingPositions` now, when marking a position closed, also:

- `realized_pnl = COALESCE(realized_pnl, unrealized_pnl)` — estimates realized P&L from the
  position's **last mark** (E*Trade's dollar `totalGain`, persisted in `unrealized_pnl` since
  v1.1.43). For a short option that expired/closed favorably this ≈ the premium kept; for stock
  it's the last gain/loss. **COALESCE never overwrites** a value already set by the
  transaction-history sync, which remains the authoritative exact source.
- `exit_date = COALESCE(exit_date, <detection time>)` and an `exit_notes` flag making clear it's
  a sync-close estimate ("run Sync Closed Positions for exact figures").

### Scope
- Applies to positions closed **going forward** — the estimate needs the last mark, which is only
  stored from v1.1.43 on. A position closed before these builds (no stored mark) stays blank;
  Sync Closed Positions pulls its exact figure from transaction history.
