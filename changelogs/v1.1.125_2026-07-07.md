# v1.1.125 — 2026-07-07

## Filters sidebar: template descriptions as hover tooltip, not always-visible text

User request: the Filters screen's left sidebar was running out of vertical space and showing
a scrollbar, because every template card renders a 1-2 sentence description below its label at
all times. With the growing list of filter templates, that's a lot of permanent real estate for
text most users only need occasionally.

### What shipped

Each sidebar card (`src/renderer/src/views/FiltersView.tsx`) now shows icon + label + the
existing batch-precompute match-count badge only. The description text moved into a hover
tooltip, triggered by a small "?" icon next to the label.

### Reused, not reinvented

`PayoffView.tsx` already had a portal-based `InfoTip` component (small "?" trigger, dark-themed
box rendered at `document.body` via `createPortal` so it's never clipped by a scrolling
container, auto-flips above/below depending on viewport position) used for its P&L/Greeks stat
tooltips. Rather than build a second tooltip implementation for Filters, extracted it into
`src/renderer/src/components/InfoTip.tsx` and imported it in both views. `PayoffView.tsx` had no
other uses of `createPortal`, so that import was removed there too — pure extraction, no
behavior change to its existing tooltips.

### Files

`src/renderer/src/components/InfoTip.tsx` (new), `src/renderer/src/views/FiltersView.tsx`,
`src/renderer/src/views/PayoffView.tsx`.
