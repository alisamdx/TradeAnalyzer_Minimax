# v0.23.6 — 2026-06-05

## fix: Batch Jobs page — scrollbar missing, top panels scroll off-screen during live run

The Batch Jobs view had no scroll container. When the Live Activity panel appeared
during a running job, the total page height exceeded the viewport and the top panels
(Registered Jobs + Run History) were pushed above the visible area with no way to
scroll back to them.

Fix: wrapped the BatchView content in a `flex: 1; minHeight: 0; overflowY: auto`
outer div, matching the scroll pattern used by other views. The entire page now scrolls
correctly inside the `.main` flex column.
