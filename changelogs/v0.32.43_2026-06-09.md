# v0.32.43 — 2026-06-09

## Fixed

### My Stocks: IV showing as thousands percent

**Problem**: IV values in the My Stocks (ConvictionView) screen were displaying as e.g. 3172.6% instead of 31.7%.

**Root cause**: `conviction-service.ts` had three locations that mapped `iv_history.atm_iv` through `* 100`, with a comment "decimal → percentage". This was wrong — per project conventions, `atm_iv` is stored as a percentage (38.82, not 0.3882). The multiplication was doubling the exponent.

**Fix**: Removed all three `* 100` multiplications:

1. `list()` — `latestIv` assignment and `computeIvRank` call
2. `recommend()` — `ivs` array construction  
3. `get()` — `ivRows` array construction

The `computeIvRank()` function uses relative min/max arithmetic so its output was numerically equivalent regardless of scale — but the raw `iv` value returned to the renderer was 100× too large.

**Files changed:**
- `src/main/services/conviction-service.ts` — three `* 100` removals
