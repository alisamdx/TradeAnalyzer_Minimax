# v1.1.229 — 2026-09-11

## The lint cleanup ships, and lint now gates the tests

Everything here is behaviour-preserving by construction. It ships as a version rather than silently
because it touches code that runs: a version number is what makes "the binary you have" answerable.

### What changed in shipped code

| File | Change | Why it cannot alter behaviour |
|---|---|---|
| `routes-fundamentals/options/strategy-lab/validation.ts` | `/^[A-Z][A-Z0-9.\-]{0,9}$/` → `[A-Z0-9.-]` | `-` is last in the character class, so it was already literal; the escape was noise. Same accepted ticker set. |
| `alerts-service.ts` | `input.hasOwnProperty(k)` → `Object.prototype.hasOwnProperty.call(input, k)` | Identical result; the call form survives an object with a shadowed `hasOwnProperty`. |
| `leaps-csp-service.ts` | `void dte;` after `return` deleted, parameter renamed `_dte` | The statement was unreachable — it never executed. |
| `PortfolioView`, `RetrospectView` ×2, `StrategyLabView` | `s.has(x) ? s.delete(x) : s.add(x);` → explicit `if/else` | Same branches, same effects. |
| `BatchView`, `EarningsCalendarView`, `PayoffView` ×3, `PortfolioView`, `RetrospectView`, `TestApiView` ×4 | literal `"`/`'` in JSX text → `&quot;`/`&apos;` | Renders identically. |
| `preload/index.ts` | 5 IPC wrappers typed (`Electron.IpcRendererEvent`, `Parameters<typeof callback>[0]`) | Types erase at build. |
| `backtest-engine.ts` | 4 row interfaces replace `any` at 11 sites | Types erase at build. Typecheck passing is evidence the declared shapes match what the queries return. |
| `VolumeProfile.ts` | typed from `fancy-canvas` / lightweight-charts exports | Types erase at build; the `as` casts they replace were no-ops. |
