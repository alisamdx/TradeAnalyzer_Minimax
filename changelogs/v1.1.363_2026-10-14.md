# v1.1.363 — 2026-10-14

## Equity bid/ask from E\*Trade; QC-303 reads it (`core` 0.6.76, `next` 0.4.61, dictionary v26)

Pilot-exit item #16 (never-fired checks). QC-303 (crossed market) had never evaluated a row: v1.1.257 found all 13,211 `raw_eod_quote` rows `quote_status = omitted`, because Polygon Stocks Starter sends no `lastQuote`. Quotes are in Stocks Advanced (~$199/mo per published third-party tiers). E\*Trade's quote endpoint already serves bid/ask, and the collector already calls it for VIX and earnings dates, so the data comes from there at no cost.

**The live response, read before the parser was written** (TA1 → Misc → Test API, AAPL, 2026-10-14 19:59:57 EDT):
- `All.bid` 344.63, `All.ask` 345.2, `bidSize` 80, `askSize` 360, all numbers.
- `bidTime`/`askTime` are ET wall-clock strings with a zone label: `19:59:57 EDT 10-14-2026`.
- **`ahFlag` is the string `"true"`**, the same trap as the chain's `inTheMoney` `"y"`/`"n"`.
- `quoteStatus` `CLOSING`; `dateTimeUTC` epoch seconds.
- **After the close, `All.bid`/`All.ask` are the extended-hours quote**: identical to `All.ExtendedHourQuoteDetail`. So the 17:05 ET capture is an after-hours quote, not the closing one.

**What changed**
- **`raw_etrade_quote`** (new, domain `quotes`, append-only, rule-driven). `bid` and `ask` each have their own status, so an after-hours book with one side keeps it; a `0` is stored as `0`. Sizes are plain nullable: under a shared status the coherence CHECK would make a missing size throw inside the capture and blank the price. `bid_time`/`ask_time` with status (`invalid` for an unexpected shape), `ah_flag`, `provider_quote_state` (verbatim `quoteStatus`), `provider_timestamp`.
- **Phase `quotes_etrade`** (`runEtradeQuotesPhase`), right after `quotes`, its own entry in `DAILY_PHASES` so QC-006 sees a failure instead of it hiding behind a good Polygon snapshot. 25 symbols per call (E\*Trade's documented limit; `overrideSymbolCount` deliberately not used), about 44 calls for the universe. **No batched quote path had ever been sent by either app**, so a batch that comes back non-2xx is retried one symbol per call. The phase reports tickers that were asked, answered and still absent.
- **Parser `makeEtradeQuoteIngest`** (recipe `etrade_quote`, replayable). Rows are keyed on the symbol asked (v1.1.257); an answer for a symbol not asked is dropped.
- **QC-303** reads the latest `raw_etrade_quote` row per ticker for the date (`row_id` breaks an `observed_at` tie), counts only rows with both sides `ok` and above zero, fires on any crossed quote, and splits the crossed count by `ah_flag` in its detail and evidence. The changed description makes it a **new registry version**, so it returns to the never-fired list and needs a ruling once it has run.

**Not verified yet.** The batched comma path and the night's after-hours crossed rate are tomorrow's 17:05 run. If after-hours crossed quotes turn out to be common, QC-303 will be a nightly warning and the ruling is where to decide whether to scope it.
