# v0.23.9 — 2026-06-05

## fix: Daily IV Update — no-options tickers counted as failed instead of skipped

Two types of tickers in the universe were being marked `failed` when they should
be `skipped` — they have no listed options and E*Trade legitimately cannot serve them:

**Pre-filter (before API call):**
- Tickers with dots in the symbol (e.g. `LEN.B`, `CWE.A`, `UHA.B`) are class shares.
  E*Trade returns a 400 "invalid symbol" for these. Now detected by `ticker.includes('.')`
  and skipped immediately without burning an API call.

**Catch block (after API call):**
- `"E*Trade returned non-JSON"` — E*Trade returned XML (200 OK but no JSON) for tickers
  with no listed options (e.g. NVR, DDS, GLIBA, SEB, UI). Now classified as `skipped`.
- `"API error (400) code 10033"` — "The symbol entered is invalid." Also classified
  as `skipped`.

Real failures (auth errors, network errors, unexpected 5xx) still count as `failed`.
