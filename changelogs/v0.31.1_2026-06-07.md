# v0.31.1 — 2026-06-07

## Fix: Earnings startup refresh

### Problem
The "Earnings Refresh" batch job (runs on app open for all portfolio + watchlist + conviction tickers) was designed in v0.31.0 but the `useEffect` call in `App.tsx` was never added.

### Fix
Added a fire-and-forget `useEffect` in `App.tsx` that calls `window.api.earnings.refresh([], false)` on mount:
- Empty array → routes to `EarningsService.refreshAllRelevant()` (portfolio + watchlists + conviction)
- `force = false` → respects 24h cache TTL (no-op if data is fresh)
- Errors silently swallowed — earnings refresh is non-critical

### Files changed
- `src/renderer/src/App.tsx` — added startup earnings refresh `useEffect`
