# v1.1.195 — 2026-09-06

## chore — the build guard follows the new exe's rename

`scripts/check-not-running.mjs` watches for `TradeAnalyzer2` rather than
`TradeAnalyzer 2`.

The new application's executable was renamed to `TradeAnalyzer2.exe` (operator
decision; its *display* name stays "TradeAnalyzer 2"). The guard matches the
**process** name, which follows the executable filename and not `productName`,
so it had to move with it. Left stale, it would have silently stopped seeing the
new app and allowed a build to run over a locked file — a failure that looks
like a corrupt bundle rather than a running process.

`packages/next/test/app-identity.test.ts` now reads the executable name out of
that package's `package.json` and asserts this file watches for exactly it, so
the two cannot drift apart again.

No behaviour of the existing app changed.
