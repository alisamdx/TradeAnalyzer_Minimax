# v0.32.77 — 2026-06-11

## Add: SEC EDGAR fundamentals test in Test API screen

### Purpose

First step toward replacing the plan-restricted Polygon `/vX/reference/financials`
endpoint with free SEC EDGAR XBRL data. This tab lets you validate that EDGAR has
the required financial data before building the full provider.

### What the tab does

1. **CIK resolution** — fetches `https://www.sec.gov/files/company_tickers.json`
   on first use (~500 KB), builds a ticker→CIK map, caches it for the session.

2. **Company facts** — fetches `https://data.sec.gov/api/xbrl/companyfacts/CIK{padded}.json`
   (free, no auth, `User-Agent` header required).

3. **Field coverage check** — validates the 11 US-GAAP concepts that `computeRatios()` needs:

   | Role | Primary concepts tried |
   |------|------------------------|
   | Revenue | Revenues, RevenueFromContractWithCustomer… |
   | Net Income | NetIncomeLoss |
   | Operating Income | OperatingIncomeLoss |
   | Depreciation & Amort | DepreciationDepletionAndAmortization |
   | Stockholders' Equity | StockholdersEquity, …AttributableToParent |
   | Current Assets | AssetsCurrent |
   | Current Liabilities | LiabilitiesCurrent |
   | Long-term Debt | LongTermDebt, LongTermDebtNoncurrent |
   | Cash & Equivalents | CashAndCashEquivalentsAtCarryingValue |
   | Operating Cash Flow | NetCashProvidedByUsedInOperatingActivities |
   | CapEx | PaymentsToAcquirePropertyPlantAndEquipment |

4. **Results table** — per field: ✓/✗, concept name resolved, latest annual (10-K)
   value + date, latest quarterly (10-Q) value + date, filing counts.

5. **Concept browser** — shows first 40 GAAP concepts present in this company's filings;
   highlights concepts already mapped (green border).

6. **Raw sample** — collapsed by default; shows last 5 entries of the first found concept.
