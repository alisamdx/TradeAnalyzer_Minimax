# v0.28.3 — 2026-06-06

## Fix: Close trade now works — direct DB write instead of external CLI

**Root cause:** The previous `closeTrade` IPC handler spawned `npm run agent:close-trade` in the agent project directory. This requires the TraderAgent project to have that specific npm script. If the script doesn't exist, the spawn succeeds (no error thrown) but nothing actually happens in the database.

**Fix:** `closeTrade` now writes directly to the agent SQLite database using the same writable-connection pattern as `deleteTrade` (opens a separate `new Database(path)` since the main connection is read-only).

**What close does:**
1. Looks up the trade's current option mid from the latest theory check
2. Computes `actualPl = (entryPremium - currentOptionMid) × 100` if option price is available, otherwise `null`
3. Sets `status = 'closed'`, `close_date = today`, `close_reason`, `actual_pl`
4. Emits `agent:phase-done` so the trades list refreshes immediately
5. Triggers AI learning capture (unchanged)
