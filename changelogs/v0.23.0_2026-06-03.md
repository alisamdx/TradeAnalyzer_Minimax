# v0.23.0 — 2026-06-03

## Paper Trading / Retrospect

Closes the feedback loop on Daily Intelligence Brief quality. Every brief run now auto-captures all post-liquidity-gate picks as paper trades and the new Retrospect screen lets you track their performance over time.

### New files
- `migrations/025_paper_trades.sql` — `paper_trades` table with `UNIQUE(ticker, brief_strategy, brief_date)`
- `src/main/services/paper-trading-service.ts` — `PaperTradingService` (auto-capture, P&L, close, expire, summary, accuracy)
- `src/main/ipc/ipc-paper-trading.ts` — 10 IPC handlers
- `src/renderer/src/views/RetrospectView.tsx` — 4-tab Retrospect screen

### Modified files
- `src/shared/types.ts` — 8 new types: `PaperTrade`, `PaperTradeWithPnl`, `PaperTradeSummary`, `StrategyBreakdown`, `RetroSettings`, `RetroStrategySettings`, `BriefAccuracy`, status/verdict/outcome enums
- `src/main/index.ts` — instantiate `PaperTradingService`, register IPC, pass service to `DailyIntelligenceBriefJob`
- `src/main/services/jobs/daily-intelligence-brief-job.ts` — `autoCapture()` called after Stage 6 for each strategy; failures are caught and logged but never fail the brief job
- `src/preload/index.ts` — `window.api.paper.*` namespace (10 methods)
- `src/renderer/src/App.tsx` — `'retrospect'` view type, import, nav button, route
- `src/renderer/src/views/DailyBriefView.tsx` — accuracy chip on history date buttons; accuracy banner when historical date selected
- `src/renderer/src/styles.css` — Retrospect and accuracy banner styles

### Key design decisions
- Auto-capture is server-side (end of brief job) — no user action needed
- Same-day re-runs upsert via `ON CONFLICT(ticker, brief_strategy, brief_date) DO UPDATE` — only if status = 'open'
- P&L uses `historical_prices` (no live API calls — Tier 1)
- Exit price auto-filled from latest `historical_prices` close
- Verdict thresholds are user-configurable per strategy via Settings tab (defaults: 5% threshold for directional, 8% for income; Close Signal at DTE ≤ 7 or move > 15%)
- Brief accuracy requires ≥ 3 closed picks to avoid misleading 100% on 1 trade
