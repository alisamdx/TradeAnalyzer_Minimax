# v1.1.215 — 2026-09-09

`@tradeanalyzer/core` 0.3.6, dictionary **v10**.

Hosts the rest of NewApp's B7b except the IV view. Detail in
`NewApp/CHANGELOG.md`; what changes in this application:

- **`collector-oneshot` now executes `bootstrap_iv`** (the third implemented
  one-shot, after `universe_seed` and `backfill_bars`). It cannot run until an
  IVolatility subscription exists — that is a spend decision, not a build one —
  but the job, its parser and its wiring are complete and fixture-tested, so the
  pull is a Run Now when the decision is taken.
- The job's operator line reports **`outOfBand`** — values outside the fraction
  band `(0, 5)` — beside the row count. If those two numbers are equal the
  **unit** is wrong, not the data, and the line says so in words.
- Dictionary **v9 → v10**: `accepted`, `accepted_at`, `accepted_note` on
  `ext_iv_history`, declared as `mutableColumns`. The IV value stays frozen; the
  acceptance decision is the only thing that may be recorded later. Applies in
  place through the empty-table rebuild — no reset.
- The gate now runs `checksFor(db)` rather than the static `ALL_CHECKS`, so the
  two bootstrap checks register only once there is a series to compare against.

`1,253` tests here, `351` in `core`.
