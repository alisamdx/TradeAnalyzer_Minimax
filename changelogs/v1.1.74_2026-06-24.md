# v1.1.74 — 2026-06-24

## Configurable auto-backup location

### What
Auto-backups previously always went to `userData/backups/auto`. You can now choose where they land
— e.g. a cloud-synced folder (OneDrive/Dropbox) or an external drive — so they survive a machine
loss without manual copying.

### How
- New `autoBackupDir` setting (`''` = default app-data location).
- New `settings:pick-directory` IPC opens a native folder picker (`openDirectory` + `createDirectory`),
  exposed as `window.api.settings.pickDirectory()`.
- Settings → **Backup → Automatic Backup** gains a **Backup folder** row showing the effective path,
  with **Choose…** and (when customized) **Reset to default** buttons.
- `runAutoBackupIfDue` reads `autoBackupDir` and writes into a dedicated
  **`TradeAnalyzer-AutoBackups`** subfolder of the chosen directory. This scoping is deliberate: the
  newest-5 prune deletes only `*.zip` in that subfolder, so it can never remove other files in a
  shared folder you point it at.

### Tests
Added a case asserting a custom `autoBackupDir` writes into `<dir>/TradeAnalyzer-AutoBackups/` and
does not touch the default location. Full suite **705 passing**.
