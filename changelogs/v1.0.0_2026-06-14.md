# v1.0.0 — 2026-06-14

## Milestone: v1 decision-support app is feature-complete

This release is the version marker that closes out v1 and opens the v2 execution
phase. It carries no behavior change — it draws the line.

### What v1 is
A single-user Electron desktop app for a retail options/swing trader that:

- screens the S&P 500 + Russell 1000 + ETF universe,
- runs five analysis modes and a configurable 6-strategy scoring engine
  (buy / income / wheel / bullish / bearish / inflection),
- produces a daily AI intelligence brief with an adversarial critic,
- replays the brief point-in-time for backtest validation (Brief Replay),
- models multi-leg option payoffs,
- tracks a portfolio synced read-only from E\*Trade,
- surfaces earnings/news risk and runs strategy/LEAPS/collared-LEAPS screeners,
- backtests picks (per-ticker and aggregate, with real option/dollar P&L).

Verified against the consolidated v1 spec in `Requirements/spec/`
(FR-* / NFR-* acceptance tests). The app is **read-only at the broker** — it
recommends and validates, it does not act with money.

### Why cut v1 now
The next step is a categorical shift: an **automated execution** subsystem that
places and closes real trades. That flips the system's risk posture (fail-closed,
audited, reconciled) and deserves its own requirement set behind a clean version
line. v1.0.0 separates *decision-support* (done) from *execution* (next).

### What's next (v2 — not in this release)
Headless execution core + Electron control panel; **semi-auto** (every order
proposed by the core, confirmed by the user before it goes live); a **segregated
IBKR account** trading paper first, then real capital under a hard in-app risk
governor (capital ceiling, per-trade and daily-loss limits, kill switch). New
requirement docs to follow. See `.ai/AI_CONTEXT.md §11` (Open decisions).
