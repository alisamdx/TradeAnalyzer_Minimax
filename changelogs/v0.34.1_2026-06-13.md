# v0.34.1 — 2026-06-13

## Backtest: guide toward IV-accurate start dates

iv_history only goes back ~1 year (2025-05-29), so backtests starting earlier were
silently priced from realized vol, not IV — undermining the v0.33.8 IV pricing.

- BacktestEngine.ivHistoryStart() returns MIN(iv_history.date); IPC backtest:iv-coverage;
  preload backtest.ivCoverage().
- New Backtest form defaults its start date to the IV-history start (when available) and
  sets the date input's min to it. Below the date range:
    - start < IV start → ⚠ 'premium priced from realized vol' + one-click 'Use {date}'.
    - start >= IV start → '✓ IV-priced (from {date})'.
- The form re-keys on the loaded IV-start so the async default applies.
