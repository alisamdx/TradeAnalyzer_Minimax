# v0.32.99 — 2026-06-13

## Inflection strategy — Phase 2: scoring + replay validation

Adds `inflection` as a 6th scoring strategy and wires it into Brief Replay so the
breakout-credit-spread thesis can be validated inside the app's own pipeline before it
reaches the live brief (Phase 3).

### What

- **`ScoringStrategy` += `inflection`** (scoring-service.ts + types.ts). `BASELINE_INFLECTION`
  config (weights sum 100): `breakoutDecisiveness` 30, `volumeSurge` 25, `breakoutIvRank` 25,
  `breakoutAtrPct` 20.
- **All inflection signals are gated** on a fresh with-trend breakout via `hasBreakout(d)`
  (`extractSignalRaw` returns null when `breakout_state` isn't an up-break) → non-breakout
  and down-break tickers score 0 and never surface.
- **Signal population**: live path `gatherSignalData` → `loadTechnicalSignals` now selects the
  migration-041 breakout columns; replay path `brief-replay-service` computes them
  point-in-time from bars ≤ asOf.
- **Replay scores it, live brief does not (yet)**: new `REPLAY_STRATEGIES = [...STRATEGIES,
  'inflection']` drives Brief Replay; `STRATEGIES` (the live brief set) stays at 5. Phase 3
  promotes it to the live brief with the credit-vertical structure.
- **Bullish-only for Phase 2**: `hasBreakout` requires `breakout_state === 1` so the replay's
  "stock-up = win" aggregation is correct. Bearish inflection (down-break → bear call spread)
  is the immediate follow-up; it needs direction-aware replay outcomes.
- **Strategy plumbing**: added `inflection` to the `Record<ScoringStrategy, …>` maps in
  brief-report-builder, paper-trading-service (incl. `RetroSettings`), and the Daily Brief /
  Retrospect / Trade Scoring / Brief Replay views. Relevant slugs: `bull-put-spread` /
  `bear-call-spread` (constructed in Phase 3).

### How to validate

Re-run Brief Replay (it now scores `inflection` over history). The summary/charts will
include an Inflection row — confirm the top-quintile continuation/hit-rate matches the
offline finding before Phase 3 commits the live section + credit-spread structure.

### Tests

- `tests/inflection-scoring.test.ts` (4): strong up-breakout scores > 0; non-breakout and
  down-breakout score 0 (gated); more decisive/higher-volume/higher-IV ranks above marginal.
  Suite: 292 passing.
