# v0.22.28 — 2026-06-03

## Daily Intelligence Brief: email + PDF attachment

### What's new
After the Daily Intelligence Brief job completes successfully, it sends an email
with a trade-ready HTML body and a full-detail PDF attachment.

### Email body
One section per strategy (Wheel, Income, Buy, Bullish, Bearish). Each section
has a table with enough detail to place a trade from your phone:
- Rank, Ticker, Price, Grade (A+/A/B/C/F), Score (0–100)
- Structure (CSP, Call Spread, Iron Condor, etc.)
- Strike, Expiry, DTE
- Premium (credit shown green, debit shown red)
- Annualized Return, POP (probability of profit)
- Max Loss

### PDF attachment (`daily-brief-YYYY-MM-DD.pdf`)
Full detail document, multi-page:
- Cover page with date and strategy contents
- One section per strategy with all 5 picks
- Each pick card: setup details + top 5 signal contributions + full AI rationale
- Page numbers in footer

### SMTP config
Reads from `agentProjectPath/.env` — the same credentials configured in the
Agent screen (Config → Email tab). No re-configuration needed if email is
already working for position reports.

If SMTP is not configured, the email step is silently skipped — the brief
is still persisted to the DB as normal and the job reports success.

### New files
- `src/main/services/email-service.ts` — `EmailService` class (SMTP send, isConfigured check)
- `src/main/services/brief-report-builder.ts` — `buildEmailHtml()` + `buildPdf()` (pdfkit)

### New dependency
- `pdfkit@^0.18.0` — pure Node.js PDF generation, no browser required
- `@types/pdfkit@^0.17.6` (dev)
