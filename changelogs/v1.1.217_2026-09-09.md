`@tradeanalyzer/core` 0.3.7. Dictionary v10 (unchanged).

## The brief now hands its whole candidate set to the collector (NewApp 04 §8)

At the end of a run the brief calls `writeLegacyHandoff` with **every candidate
it scored** — the rejected ones too, with the gate that stopped each and how far
off it was. `daily_briefs` keeps only survivors, so the cut from 15 to 5 has
never been measurable; the losers are the control group.

### D1 is the constraint, and the design is shaped by it

The collector must not change what the brief decides or emails, so:

- **The dependency is optional and defaults to null.** Every existing test and
  any install that has never run TradeAnalyzer 2 behaves exactly as before —
  the strongest form of "cannot affect it" is a thing the brief runs
  identically without.
- **It runs after every decision is made and persisted**, is wrapped in
  `try`/`catch`, is never awaited, and nothing downstream reads its result. A
  collector problem is a collector exception. All four properties are pinned by
  a test, because "we were careful" is not a guarantee.
- The wiring resolves the shared pointer itself and returns silently when there
  is no generation, and it closes the host in a `finally` — this path opens the
  generation outside any collector run, and a handle left open would be a
  second writer nobody is tracking.

### The leg's `right` is read, never inferred

The payload is built inside the loop that already extracts the short leg,
because that is the only place a real `SetupLeg` — carrying `side` — is in
scope. Reconstructing it later from a structure slug would have been guessing.

**A leg is skipped when its side or the setup's expiration is missing**, rather
than filled in. The OSI symbol is constructed here (`osiSymbol` in `core`, 7
tests against the format a live E*Trade chain returned), and a wrong one does
**not** throw: `ref_sticky_contract.osi_symbol` is matched against
`raw_option_contract_snapshot.osi_symbol`, so a padding difference would pin a
contract tomorrow's chain phase never matches. The sticky set would look
populated and capture nothing.

`volume` crosses as a **presence** test, not `?? 0` — the same distinction that
cost 23 of 250 stored legs a false liquidity rejection.
