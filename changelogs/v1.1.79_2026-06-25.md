# v1.1.79 — 2026-06-25

## Fix: Portfolio → Payoff shows the actual held position

### Symptom
Clicking the **📐 Payoff** button on an open position in the Portfolio screen landed in the
Payoff view with the *wrong* structure. Example — a held **NOW 80-strike CSP, exp 08-21,
$4.32 entry credit** opened as **PUT $82, exp 08-07, prem $3.77, Δ −0.29, IV 63%**.

### Root cause
The button passed the position's correct strike/expiry, but the Payoff view consumed them via
its **"Opportunity navigation" path**, which *rebuilds* a structure from the live chain:
- It loads expirations via `getNearExpirations`, which returns **only the next 7 weekly
  Fridays** (≈ through 08-07 from late June). The position's 08-21 is the 9th Friday — outside
  that window — so "closest available expiry" collapsed to **08-07**.
- It then picked the **nearest strike in that weekly chain** (80 isn't listed weekly → **82**)
  and priced the leg at the **current market mid** ($3.77), with today's Δ/IV.

So the diagram was a brand-new near-term CSP approximating the holding, not the holding itself —
wrong expiry, wrong strike, and the entry credit (which sets a CSP's max profit) replaced by a
live quote.

### Fix
The Portfolio button now reconstructs the position **exactly** and routes through the Payoff
view's pre-built-legs path (the same one Strategy Lab / Daily Brief use), which honors the
legs as given. New pure, shared helper:

`src/shared/position-payoff.ts` → `positionToPayoffLegs(pos)`:
- CSP → sell put, CC → sell call, Long Put/Call → bought option, Stock → stock leg.
- Exact **strike**, **expiry**, **entry premium**, **contract quantity**.
- Greeks pass through **raw** (option-level, as stored) — `computePayoffMetrics` applies the
  side sign, so a sold put's stored −Δ becomes a positive position delta correctly.
- Returns `undefined` if an option position lacks strike/expiry → the button falls back to the
  old chain-rebuild for those edge cases.

### Tests
`tests/position-payoff.test.ts` (6): CSP/CC/Long/Stock mapping, quantity floor, and the
missing-strike/expiry → undefined fallback. Full suite green; typecheck clean.

### Note
This only changes the **entry path** — once in the Payoff view the structure is fully editable
as before, and the new **Pre-Trade Validator** (v1.1.76) now operates on your real position
when you arrive this way.
