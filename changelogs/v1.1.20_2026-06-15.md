# v1.1.20 — 2026-06-15

## Daily-brief accuracy audit (pre-real-money)

A deep-dive of the latest brief (6 strategies, 30 picks) against the generation pipeline,
hunting for internal inconsistencies that could mislead a capital decision. The core engine
held up — `selectRelevantStructure` presents direction-appropriate structures, gates behave,
missing data is honestly surfaced as null. Three genuine fixes + one documented gap.

### F1 — Critic fabricated volatility figures (fixed)

The critic's LLM context (`synthesizeVerdict`) contained **no** volatility field at all, yet
the system prompt told the model to compute an "expected 1-sigma move (annualized vol /
sqrt(365/dte))." Forced to comply with no input, the model invented precise, authoritative-
sounding numbers shown to the user as risk rationale:

| Pick | Rationale claimed | Real (lab ATM IV) |
|---|---|---|
| MRVL wheel | "140.8% implied volatility" | 104.7% |
| RKLB income | "realized vol ~108%" | not provided |
| ASTS income | "~139% annualized" | not provided |
| ON income | "realized vol of 78.4%" | not provided |

Fix: new exported `extractVolatilityContext(labResult)` pulls `{ impliedVolPct, ivRank }` from
`lab.context.currentAtmIv`/`ivRank` into the context; the prompt now uses that field for all
expected-move reasoning and **forbids** citing any volatility figure not present (null → say it
could not be measured). Rationale-accuracy only — no change to which trades are taken or sized,
so no FR-SEY-5 validation required.

### F2 — Breakeven-distance wrong for non-straddle income structures (fixed)

`breakevenDistancePct = |netCredit| / price` equals the breakeven distance only for an at-the-
money short straddle. For short strangles, iron condors, and OTM-strike CSPs the short strikes
sit away from spot, so it understated the true breakeven ~10× — MRVL's iron condor (shorts
230/450, spot 309) read **2.3%** when the nearest breakeven is **~28%** — and the critic then
raised a spurious "narrow breakeven" concern, and the `thin_breakeven` rule could falsely fire
on structurally-wide condors.

Fix: exported pure `breakevenDistancePct(legs, netCredit, price)` computes the distance to the
nearest `shortStrike ± credit` using only the **short** legs (long wings cap loss, not
breakeven); leg `side` is used when present, inferred from strike-vs-spot otherwise. Applied to
both the LLM context value (income) and the `thin_breakeven` rule (income/wheel).
`docs/formulas.md#breakeven-distance` rewritten.

### F4 — Brief diagnostic repaired (`scripts/brief-deep-dive.mjs`)

The tool used to sanity-check a brief was itself broken: crashed on a stale `analysis_snapshots`
schema; printed `undefined` in the verdict summary (read `f.rule`, flags carry `f.key`);
displayed `scores[0]` (overall top structure) instead of the strategy-relevant one — the artifact
that made bearish picks *look* like they had bullish structures; and omitted the 6th `inflection`
strategy. Now shows the actual presented structure, all six strategies, a corrected freshness
query (`technical_signals.computed_at`), and a "no relevant structure" anomaly check.

### F3 — VIX always null (documented, not fixed)

Nothing writes a `'VIX'` row to `quote_cache`, and the only fetch (`briefing-service.getQuote('VIX')`)
uses Polygon's *stocks* snapshot for ticker `VIX` — but VIX is an index (`I:VIX`, an Indices-plan
ticker the Stocks Starter plan lacks), so it returns null. The critic's macro context is therefore
SPY-trend-only and its two VIX rules (wheel/income VIX>30, bearish VIX<14) are dormant. The null
path is fail-safe. A real fix needs a verified index-quote source (E*Trade `/market/quote` or a
Polygon Indices plan) and is deferred until it can be verified against the live connection rather
than shipped blind into a real-money path. Documented at the source + `CLAUDE.md` + `AI_CONTEXT §10`.

### Not changed (validated)

Bearish picks can surface on stocks in short-term uptrends (lab `directionBias: bullish`,
`trend: Sideways`), score carried by fundamental-weakness + the `rsiOverbought` signal saturating
below RSI 70. This is part of the **validated** bearish ≥70 composite (real short edge on full-year
replay); an overbought guard was already tested and rejected on the same sample (FR-SEY-5); the
critic surfaces the risk (`elevated_market_risk`, `counter_trend_itm_strike`). Deliberately not
re-engineered.
