# v1.1.41 — 2026-06-17

## Payoff "Fix" expanded to lizards and iron condors

Extends the v1.1.40 one-click 🔧 Fix (was Bull Put / Bear Call verticals only) to every
credit-vs-width strategy. Same principle throughout: keep the short/premium legs (the thesis),
narrow only the protective wing(s) toward the short(s), re-priced from the live chain at mid,
choosing the widest passing strike (least narrowing).

### Now supported
- **Bull Put Spread / Bear Call Spread** — credit ≥ ⅓ width (unchanged).
- **Jade Lizard / Big Lizard** — narrow the long CALL toward the short call so total credit ≥
  the call-spread width (the "no upside risk" condition).
- **Reverse Jade Lizard / Reverse Big Lizard** — narrow the long PUT toward the short put so
  credit ≥ the put-spread width.
- **Iron Condor / Dynamic Width Iron Condor** — two wings: greedily narrow whichever wing is
  currently the WIDER (binding) side, one chain strike at a time, until credit ≥ ⅓ × max(put
  width, call width).

The button stays hidden when the credit-vs-width rule already passes, the chain isn't loaded,
the strategy isn't one of the above, or no strike narrows enough.

### Implementation
- `src/shared/payoff-fix.ts` refactored into:
  - `wingSpecFor` + `fixSingleWing` — the generalized single-wing path (verticals + lizards),
    parameterised by side, short anchor, and the credit-to-width multiplier (⅓ for verticals,
    1 for lizards).
  - `fixCondor` — the two-wing greedy narrowing for iron condors.
  - a guard so it returns null when the rule already passes (no over-narrowing).
- `tests/payoff-fix.test.ts` (8 tests): vertical exact-strike selection + re-price; lizard and
  condor invariant checks (post-fix credit ≥ the relevant width, shorts kept, wings narrowed
  in); already-passing and out-of-scope → null. Full suite: **550 passing**.
