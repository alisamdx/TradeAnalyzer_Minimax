# v0.32.84 — 2026-06-11

## Add: dividend yield + beta (both were 100% null universe-wide)

Closes the last two gaps from the post-batch fundamentals deep-dive.

### Dividend yield

- `PolygonDataProvider.getTtmDividendsPerShare()` queries `/v3/reference/dividends`
  (included in Stocks Starter) with `ex_dividend_date.gte` = 365 days ago, in
  parallel with the existing EDGAR + ticker-details calls.
- Trailing yield = TTM regular cash dividends per share / current price × 100.
  Special dividends (`dividend_type='SC'`) excluded — a one-off payout must not
  inflate the yield the wheel/income scoring sees.
- Semantics: **0** = confirmed non-payer (API succeeded, no rows);
  **null** = unknown (fetch failed). Computed in `computeRatios()` via the new
  optional `ttmDividendsPerShare` input.

### Beta

- New `src/main/services/beta-service.ts`:
  - `computeBeta(stockReturns, marketReturns)` — pure, unit-tested:
    cov(r_s, r_m) / var(r_m); null under 200 observations or ~0 market variance.
  - `BetaService.getBeta(ticker)` — last 253 closes for ticker + SPY from local
    `historical_prices` (`adjusted_close` preferred), **joined on date** so
    holidays/gaps can't misalign the return series, then `computeBeta`.
- Zero API cost: 1,046/1,067 universe tickers already have ≥250 bars locally
  (price-gap-fill job maintains them); SPY history is current.
- Injected into `PolygonDataProvider` as an optional `getBeta` constructor callback
  (wired in `index.ts`); flows through `computeRatios()` into `DerivedRatios.beta`.
