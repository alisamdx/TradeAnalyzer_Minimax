## Added

### B-02: Daily Brief — Critic Health Trend Banner

A second slim bar appears in the Daily Brief header (below the B-01 performance banner) showing per-strategy critic pass-rate trend across the last 7 briefs.

**Display format:** `wheel ↑55% · buy →42% · bullish ↓28%`

- **Trend arrow**: ↑ improving / ↓ declining / → stable / — insufficient data
- **Pass rate colour**: green ≥60% / amber ≥40% / red <40%
- **Arrow colour**: green (improving) / red (declining) / amber (stable)
- Only visible when at least one strategy has 3+ briefs with critic data; silently absent otherwise

**How trend is determined:** the last 7 distinct calendar-date briefs per strategy are fetched. Per date, `criticVerdict.verdict` counts from the `picks` JSON are tallied. A `passRate` is computed as `passes / total` (null when fewer than 2 verdicts). Trend is set by comparing the average pass rate of the older half vs the newer half of available data points — >8pp improvement → ↑, >8pp drop → ↓, otherwise → stable. If fewer than 3 rated points exist, trend is `'insufficient'`.
