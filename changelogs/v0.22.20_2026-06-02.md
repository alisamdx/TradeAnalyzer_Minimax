# v0.22.20 — 2026-06-02

## WheelMetrics Quality Signals

Adds six new fundamental quality signals to the screener to match the high/moderate-value
metrics from the WheelMetrics Pro screener service, without requiring any new Polygon API
endpoints. All metrics derived from the existing `/vX/reference/financials` quarterly
filings response.

### New signals

| Signal | Formula | Null when |
|---|---|---|
| `FCFToNetIncome` | `(operatingCashFlow / netIncome) × 100` | netIncome ≤ 0 |
| `ROIC` | `NOPAT / (totalDebt + equity) × 100` | investedCapital ≤ 0 |
| `NetDebtToEBITDA` | `(totalDebt − cash) / (operatingIncome + D&A)` | D&A unavailable or EBITDA ≤ 0 |
| `RevenueGrowth5Y` | `((TTM_now / TTM_5Y_ago)^(1/5) − 1) × 100` | < 20 quarterly filings |
| `EPSGrowth5Y` | same CAGR on EPS | < 20 quarterly filings |
| `ValueScore (VS)` | count of 6 value criteria ≥ threshold | — (always 0–6) |
| `GrowthScore (GS)` | count of 6 growth criteria ≥ threshold | — (always 0–6) |
| `StockGrade` | VS≥4 AND GS≥4 → 3★★★; VS≥4 OR GS≥4 → 2★★; VS≥2 OR GS≥2 → 1★ | both < 2 |

### VS / GS criteria thresholds

**VS (Value Score):** RevenueGrowth5Y ≥ 5%, EPSGrowth5Y ≥ 7%, FCFToNetIncome ≥ 80%,
ROIC ≥ 15%, NetDebtToEBITDA ≤ 3, DebtToEquity ≤ 0.8.

**GS (Growth Score):** RevenueGrowth5Y ≥ 5%, EPSGrowth5Y ≥ 7%, FCFToNetIncome ≥ 80%,
ProfitMargin ≥ 10%, ROIC ≥ 15%, NetDebtToEBITDA ≤ 3.

### Polygon data notes

- **D&A**: extracted from `income_statement.depreciation_and_amortization` (TTM summed). If
  Polygon does not return this field, `NetDebtToEBITDA` returns null — consistent with FR-SE-03.
- **Cash**: extracted from `balance_sheet.cash_and_cash_equivalents` (latest filing, point-in-time).
- **5Y CAGR**: requires `filings[16..19]` (5-year-ago TTM). Quarterly filings limit bumped from
  8 → 24 in `getFundamentals()` to cover the full window.
- **ROIC tax rate**: inferred as `1 − netIncome/operatingIncome`, clamped to [5%, 50%] to
  suppress distortion from one-time tax events.

### Screener UI

Eight new columns added to the screener table: FCF/NI%, ROIC%, ND/EBITDA, Rev5Y%, EPS5Y%,
VS, GS, Grade. The Grade column renders as ★/★★/★★★. All columns are sortable and included
in CSV export.

### Cache invalidation

Existing `fundamentals_cache` rows pre-dating this version will return null for the new fields
until re-fetched (24h TTL expiry). Run **Cache → Refresh** to force immediate repopulation.
