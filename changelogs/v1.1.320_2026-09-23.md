# v1.1.320 — 2026-09-23

## Shadow log for `STALE_GREEK_MODEL_DELTA`

v1.1.319 shipped the model-delta fallback **off** and set a rule for deciding it:
compare the realized outcomes of the flagged-ticker picks it would have made
against the picks actually taken. Nothing recorded those would-be picks, though.
The guard makes the wheel skip a stale chain, so by October there would have been
nothing to score. This release records them.

- **Migration 088, `stale_greek_shadow_picks`.** One row per (date, slot, ticker,
  expiration) for each stale chain in the wheel DTE window. The row holds the
  guard's reading and the put the wheel CSP rule would pick by our Black-Scholes
  delta at the chain's own price (|delta| 0.20–0.30, bid > 0, nearest 0.25),
  together with the delta E*Trade actually sent and the contract's quote. A chain
  with no put in the band is still recorded, with a NULL strike, so the count of
  skipped chains survives. A re-fetch within a slot overwrites its row.
- **`ETradeDataProvider`** takes an optional `onStaleChain` hook. It receives the
  chain as fetched, before its Greeks are withheld, and `index.ts` wires it to
  `recordStaleGreekShadow`. A hook failure is swallowed, so logging can never cost
  a chain fetch.
- **`GET /diagnostics/stale-greek-shadow?from&to`** reads the rows. It is
  read-only, for scoring from a shell after the first picks expire (2026-10-16).

The live path is unchanged: every chain is withheld or passed exactly as before.

Tests (`tests/stale-greek-shadow.test.ts`, real migrations):

- the recorded pick is in the band by model delta, and E*Trade's stale delta for
  the same contract reads further out;
- a clean chain and an out-of-window chain record nothing;
- one row per slot;
- a NULL strike when no put qualifies;
- the reader;
- the provider hook sees the pre-withhold chain, and a throwing hook still returns
  the chain.
