# v0.33.7 — 2026-06-13

## Backtest integration — phase 1: deep-link from recommendations

Backtest was a manual, one-stock-at-a-time tool disconnected from the scan/score/recommend
flow. Phase 1 ties it to what we already recommend.

- '🔁 Backtest' action on My Stocks rows (pre-fills a CSP for that ticker) and on Daily
  Brief wheel/income pick cards (wheel→Wheel, income→CSP). Opens Backtest pre-filled —
  no manual data entry.
- Only shown where the engine applies (CSP/CC/Wheel premium strategies); buy/bullish/
  bearish/inflection brief picks don't show it.
- New `navigate-to-backtest` CustomEvent (App.tsx handler + NavEntry fields).
  `BacktestView` accepts `initialTicker`/`initialStrategy` and opens the New form
  pre-filled (ConfigForm already supported an `initial` prop).

Note: the Backtest engine models option premium via Black-Scholes from historical_prices +
realized vol — it is the option-P&L simulator Brief Replay lacks. Phase 2 will run it over
all historical brief/replay picks for a strategy and aggregate into one equity curve
(Sharpe / drawdown) — 'did trading my recommendations actually make money?'

Display/wiring only; no engine or schema change. Suite 303 passing.
