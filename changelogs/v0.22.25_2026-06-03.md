# v0.22.25 — 2026-06-03

## Fix: Daily Options Snapshot stuck on "Running"

### Root cause
`DailyOptionsSnapshotJob` calls `analysisService.analyzeTicker(ticker, 'wheel')`
for each of up to 300 tickers. This makes a live options chain call via the
configured `OptionsProvider`. If that provider is E*Trade and the OAuth token
is expired, the HTTP call hangs indefinitely — no timeout was set. The `await`
never resolved, freezing the entire job loop.

### Fix
Added `withTimeout()` wrapper (30s per ticker) around each `analyzeTicker` call.
If a ticker's options chain call doesn't return within 30 seconds, it is counted
as failed and the loop moves to the next ticker. The job will now always complete.

```
PER_TICKER_TIMEOUT = 30_000ms
```

Worst case with all 300 tickers timing out: 300 × (30s + 1.1s) ≈ 156 minutes.
In practice, timeouts only occur when the provider is unavailable — normal runs
with Polygon complete in under 10 minutes.

### Regression test
No automated test added — the hang requires a live network timeout to reproduce.
The fix is defensive: `Promise.race` against a `setTimeout` reject.
