# v1.1.12 — 2026-06-14

## Changed — Misc landing screen (sidebar declutter)

The sidebar had grown long. The four least-used tools — **Backtest**, **Test API**,
**Data Sync**, **History** — were each their own sidebar button under the *Misc* section.
They're now collapsed behind a **single 🗂️ Misc** sidebar entry that opens a landing
screen.

### `src/renderer/src/views/MiscView.tsx` (new)

A simple grid of cards, one per tool (icon + title + one-line description). Clicking a card
calls `onNavigate(view)`, which **pushes** the target view onto the nav stack — so the user
gets a **← Back** to return to the Misc screen (unlike sidebar buttons, which reset the
stack).

### `src/renderer/src/App.tsx`

- New `misc` view in the `View` union + `renderEntry` case wiring `onNavigate` to
  `setNavStack(prev => [...prev, …])`.
- The Misc section's four buttons are replaced by one `🗂️ Misc` button. It shows the
  `active` style while `misc`, `backtest`, `testApi`, `data`, or `ivHistory` is the current
  view, so the section still reads as "selected" when you're inside one of its tools.

No functionality removed — the four views and their IPC are untouched; only the navigation
path changed. No automated test (renderer-only navigation/layout change).
