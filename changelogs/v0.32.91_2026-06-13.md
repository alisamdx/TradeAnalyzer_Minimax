# v0.32.91 — 2026-06-13

## Daily Brief quality fixes: price floor + two new critic rules

**Motivation**: Daily brief deep-dive on 2026-06-13 revealed three gaps:
1. NWL ($4.92) appeared in bearish picks — no price floor in the live briefing candidate SQL
2. RKLB: strategy lab selected `short-straddle` for a stock with 98%+ IVR and 300% 1Y momentum — unlimited-risk structure on a strongly trending name
3. SYK: 10.3% OTM short put with 1.6% breakeven buffer against 27.7% realized vol — critic had no deterministic rule for thin-breakeven

**Fix 1 — Price floor (`briefing-service.ts`)**
```sql
AND CAST(json_extract(sr.payload_json, '$.lastPrice') AS REAL) >= 5
```
Added to the `BriefingService` candidate SQL alongside the existing ROE/D/E/market-cap filters. Brief Replay already enforced this via its own job filter; now the live brief matches.

**Fix 2 — `high_vol_naked_structure` rule (`critic-service.ts`)**
- Fires `warning` for `income` strategy picks where selected structure is `short-straddle` or `short-strangle` AND `priceMomentumPct.raw > 100`
- Rationale: straddles/strangles require range-bound action; a stock up >100% in a year is clearly directional; the undefined downside on the untested leg is uncompensated
- Recommends iron condor or iron fly (defined-risk income structures) instead

**Fix 3 — `thin_breakeven` rule (`critic-service.ts`)**
- Fires `warning` for `income` or `wheel` strategy when `|netCredit| / price < 2.0`
- Uses the same breakeven formula as the LLM prompt context (`netCredit` is per-contract ÷ per-share price = % buffer)
- Catches cases like SYK where premium collected is too small relative to the stock's realized movement range

**Also fixed**: `scripts/brief-deep-dive.mjs` was referencing `f.rule` and `f.message` (wrong field names); corrected to `f.key` and `f.description` per the `CriticFlag` interface.
