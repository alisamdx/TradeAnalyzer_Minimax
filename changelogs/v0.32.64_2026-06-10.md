# v0.32.64 — 2026-06-10

## Added

**Brief Trend: sortable columns**

All 12 columns in the Brief Trend table are now sortable. Click any header to sort ascending; click again to reverse. The active column shows ▲/▼; inactive columns show a faint ⇅ indicator. Null values (pending day prices, missing critic verdict, etc.) always sort to the bottom regardless of direction.

Sort is client-side only — no additional IPC calls. The sort state is scoped to the component so it resets naturally when you change the brief date or strategy filter.
