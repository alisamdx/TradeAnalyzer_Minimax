# v0.26.0 — 2026-06-06

## AI Critic — Second-Opinion Engine for the Daily Brief

Every Daily Brief pick now receives an independent adversarial assessment from a skeptic-prompted Claude haiku model, displayed inline on each pick card.

### How it works

Stage 5b (new) runs after AI synthesis (Stage 5) and before persistence (Stage 6). It operates in two steps per pick:

1. **Rule-based pre-checks** (deterministic, no API calls) — 6 checks fire against pick data:
   - `trend_strategy_conflict` — strategy's trend requirements vs. observed trend signal
   - `low_liquidity` — Strategy Lab liquidityScore just above the hard gate (< 6/15), or unvalidated pick
   - `critical_signal_missing` — top-2 weighted signals have `missing: true` (scored 0 due to null data)
   - `score_concentrated` — single signal contributes > 50 points of the composite score
   - `cross_strategy_conflict` — ticker appears in both Bullish and Bearish picks
   - `elevated_market_risk` — VIX / SPY 200MA regime conditions conflict with the strategy type

2. **LLM synthesis** — Claude haiku with adversarial system prompt receives pick context + pre-check flags, writes a 2-sentence verdict and emits `{"verdict":"pass|caution|flag","confidence":"high|medium|low"}`. If the API key is absent, rule checks alone determine the verdict at `confidence: low`.

All 25 pick calls run in parallel (`Promise.allSettled`). Stage 5b adds ~$0.05/day to AI cost; combined with Stage 5 total is ≤ $0.10/day.
