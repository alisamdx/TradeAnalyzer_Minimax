# v0.22.16 — 2026-06-01

## Trade Scoring Config — full UI redesign

Complete visual overhaul of the Trade Scoring Config view. Previously had no
CSS applied — all inputs and labels rendered as raw unstyled HTML.

### Layout

- **Strategy tabs** — pill-style horizontal tabs with emoji prefix (🎡 Wheel,
  🐂 Bullish, etc.), accent-coloured active state, right-aligned "changes take
  effect on next Brief run" note
- **Signal table** — sticky header + scrollable body with 4-column CSS grid
  (toggle · 36px | label · 220px | weight · 110px | description · 1fr)
- **Phase 2 divider** — centred rule separating available vs. not-yet-available
  signals
- **Total row** — green when 100%, red with warning when off
- **Footer actions** — version label input + Reset to Baseline + Save Config,
  fixed to bottom of view

### Signal rows

- **Direction badge** — `↑` green (higher better), `↓` amber (lower better),
  `◎` blue (target range) — visible at a glance for each signal
- **Weight bar** — thin green gradient bar under the number input showing
  relative weight proportion (0–100%)
- **Data source** — italic muted line under signal name
- **Phase 2 badge** — purple pill "Phase 2" on disabled signals
- Disabled rows (unchecked or Phase 2) rendered at 40% opacity

### Files changed

- `src/renderer/src/views/TradeScoringView.tsx` — full component rewrite
- `src/renderer/src/styles.css` — Trade Scoring section added
