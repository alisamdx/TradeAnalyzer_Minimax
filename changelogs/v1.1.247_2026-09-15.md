# v1.1.247 — 2026-09-15

## Day report: no false alarms before a day is over

### Why

`scripts/day-report.mjs --date 2026-09-15`, run at 01:10 ET, raised seven attention items. Four were false:

- "Expected job daily-intelligence-brief / data-collector / collector-watchdog has no run on this trading day": none of them was due yet.
- "Collector ran but wrote no daily gate report": the only collector run was the operator's manual `universe_seed`, which never writes a gate report.

The same report showed the boot line `collector jobs registered (disabled — manual runs only, no claim loop)`. It was hand-written for the v1.1.206 state and was never updated when migration 082 re-enabled the schedules.

### Changes

1. `day-diagnostics.ts`: `dayIsComplete(date, now)` is true for a past ET date, or for today at or after 20:00 ET. `buildAttention(report, now)` checks for missing expected jobs, and for a trading day with no daily collector run, only when the day is complete. The "no gate report" check looks at daily runs only (`run_kind = 'daily'`). `buildDayReport` passes its own `generatedAt` as `now`.
2. `index.ts`: the `boot:collector` log line lists each collector job's state from `batch_jobs`: `manual only`, `scheduled HH:MM`, or `enabled, no daily schedule`.

### Tests

`tests/day-diagnostics.test.ts`:
- the 01:10 ET case raises nothing
- a missing daily run is flagged after 20:00 even when a manual run exists
- the 19:59 / 20:00 ET boundary
- existing cases pinned to a later `now`
