# v0.24.3 — 2026-06-05

## feat: Daily Screener batch job (PERF-7)

Closes the gap where the Daily Brief and Options Snapshot would score stale candidates
if the user hadn't manually opened the Screener tab that day.

### Problem
`screen_results` was only written when the Screener tab was opened (auto-runs on mount)
or when the agent called `POST /api/v1/screener/run`. The batch sequence included
Market Sync (which refreshes `quote_cache` + `fundamentals_cache`) but had no step to
re-run the screener against the freshly synced data. The Daily Brief was reading from
whatever `screen_results` row existed — potentially days old.

### Fix

**New `DailyScreenerJob`** runs after Market Sync ETFs in the sequence:
- **Pass 1**: S&P 500 + Russell 1000, strict mode — uses the user's saved default preset
  from `screen_presets`; falls back to DEFAULT_FILTER_SPECS enabled defaults if no
  preset is saved.
- **Pass 2**: ETF universe, soft mode — filters: avg daily volume ≥ 500 k + price ≥ $10.
  ETFs don't have fundamental data (ROE, P/E, etc.) so only liquidity and price are checked.
- Each pass saves its own `screen_runs` row. Both runs complete in seconds since the
  caches are already warm from Market Sync — no network calls.

**`loadCandidates` updated in both `DailyIntelligenceBriefJob` and `DailyOptionsSnapshotJob`:**
- Now reads ALL `screen_runs` rows created today (ET calendar date) instead of just the
  single most recent row.
- Merges results across runs, deduplicating by ticker (keeps highest `passScore` if a
  ticker appears in both the stocks run and the ETF run).
- Falls back to the single most-recent run when no today-runs exist — backward compatible
  with manual screener usage.

### Batch sequence (updated)
1. Daily Market Sync (Stocks)
2. Daily Market Sync (ETFs)
3. **Daily Screener** ← new, sequence position 3
4. Daily Price Gap Fill
5. Daily Technical Signals
6. Daily IV Update
7. Daily Options Snapshot
8. Daily Intelligence Brief
