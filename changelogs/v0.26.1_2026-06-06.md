# v0.26.1 — 2026-06-06

## Payoff Visualizer — Full Strategy Lab Template Dropdown + Expanded Recognition

### Templates

Replaced the 5-button flat template grid with a grouped `<select>` dropdown covering all 31 Strategy Lab strategies. Strategies are organized into 6 groups matching Strategy Lab categories:

| Group | Strategies |
|---|---|
| Neutral / Bullish Bias | Short Naked Put (CSP), Short Put Vertical, Jade Lizard |
| Neutral / Bearish Bias | Short Naked Call, Short Call Vertical, Reverse Jade Lizard |
| Neutral | Short Strangle, Short Straddle, Iron Condor, Dynamic Width Iron Condor, Iron Fly |
| Bullish | Covered Call, Long Call Vertical, Big Lizard, PMCC, Call Calendar, Call Butterfly, Call Zebra |
| Bearish | Long Put Vertical, Covered Put, Reverse Big Lizard, PMCP, Put Calendar, Put Butterfly, Put Zebra |
| Complex | Put/Call Front Ratio, Put/Call Broken Wing Butterfly, Call/Put Broken Heart Butterfly |

Selecting a strategy builds approximate legs (with `premium: 0` so user fills from chain). Multi-quantity legs (butterfly centers, zebra buys, front ratio sells) use the `quantity` field. Dropdown resets to placeholder after applying.

### Strategy Recognition (`recognizeStrategy`)

Expanded from 11 patterns to 30+. New patterns added:

- **Jade Lizard**: sell OTM put + sell OTM call + buy farther OTM call
- **Big Lizard**: sell ATM put + sell ATM call + buy OTM call (distinguished by near-equal short strikes)
- **Reverse Jade Lizard**: buy OTM put + sell OTM put + sell OTM call
- **Reverse Big Lizard**: sell ATM put + sell ATM call + buy OTM put
- **Covered Put**: short stock + sell put
- **Call/Put Zebra**: 2 long ATM + 1 short OTM (same type)
- **Call/Put Front Ratio**: 1 long + 2 short at farther strike
- **Call/Put Butterfly**: 2 buys flanking 2 sells at same middle strike (symmetric wings)
- **Call/Put Broken Wing Butterfly**: same as butterfly but asymmetric wings
- **Iron Fly**: iron condor where short legs share the same strike
- **Call/Put Calendar**: same strike + same side, different expiries
- **Poor Man's Covered Call/Put**: deep ITM long + far DTE vs short OTM different DTE
- **Short/Long Straddle vs Strangle**: distinguished by near-equal strikes on the short/long legs

Recognition uses quantity-aware totals (`tBC`, `tSC`, `tBP`, `tSP`) so it correctly identifies strategies built with `quantity: 2` legs (single leg representing the butterfly center or zebra pair).
