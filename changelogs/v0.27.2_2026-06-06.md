# v0.27.2 — 2026-06-06

## PDF legs table: gamma, theta, vega per leg

Each leg row in the strategy setup table now shows all four Greeks:

| Column | Description |
|--------|-------------|
| DELTA  | Signed delta (e.g. +0.35, -0.28) |
| GAMMA  | Gamma per $1 move (e.g. +0.012) |
| THETA  | Theta per calendar day (e.g. -0.08) |
| VEGA   | Vega per 1% IV move (e.g. +0.15) |

Values are sourced directly from the Polygon option chain contract and stored on `SetupLeg`. Displayed as `—` when the data point is null.
