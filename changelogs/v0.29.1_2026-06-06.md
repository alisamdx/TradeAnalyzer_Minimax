# v0.29.1 — 2026-06-06

## Phase 2: Cross-pollinate Brief ideas into the external TraderAgent

Two new API endpoints on the Fastify server (127.0.0.1:7432) that the external TraderAgent CLI can call during its `decide` phase.

### 2a — AI Critic gate before entry

**Endpoint**: `POST /api/v1/critic/evaluate`

The Agent calls this after it selects a candidate ticker. If the verdict is `flag`, the Agent blocks the trade entry. If `caution`, it logs a warning in the rationale.

**Request body**:
```json
{
  "ticker": "MSFT",
  "strategy": "wheel",
  "compositeScore": 87,
  "signals": { "ivRank": { "raw": 72, "normalized": 72, "weight": 30, "missing": false } },
  "price": 425.50,
  "aiRationale": "...",
  "strategyLabResult": { ... },
  "allPicksByStrategy": { "bullish": ["AAPL"], "bearish": [] }
}
```

**Response**: A `CriticVerdict` (`verdict`, `confidence`, `flags[]`, `rationale`, `generatedAt`).

Runs all 7 deterministic rule checks (trend alignment, liquidity, critical signal missing, score concentration, cross-strategy conflict, market risk). If an Anthropic API key is configured, adds LLM synthesis via Claude Haiku. Degrades gracefully to rule-only verdict if API key is absent.

### 2b + 2c — Strategy Lab in decide phase / Multi-strategy expansion

**Endpoint**: `GET /api/v1/strategy-lab/:ticker?excludeStock=true`

The Agent calls this before choosing a structure for the candidate ticker. Instead of always defaulting to CSP (wheel) or CC, it picks the structure returned in `recommendation.bestOverall` (or `bestIncome`/`bestBullish`/`bestBearish` based on its IV regime + direction logic).

**Response**:
```json
{
  "ticker": "MSFT",
  "context": { "ivRank": 72, "directionBias": "bullish", ... },
  "scores": [ { "slug": "iron-condor", "totalScore": 84, "grade": "A", ... }, ... ],
  "recommendation": {
    "bestOverall": { "slug": "iron-condor", "totalScore": 84, ... },
    "bestIncome":  { "slug": "short-strangle", ... },
    "bestBullish": { "slug": "long-call-vertical", ... },
    "bestBearish": { "slug": "long-put-vertical", ... }
  }
}
```

`excludeStock=true` filters out strategies requiring stock ownership (covered call, PMCC) — recommended for the Agent which doesn't hold stock.
