# v1.1.343 — 2026-10-03

## The spread shadow report re-judges earnings-gate rejections under today's rule

**Symptom.** The report's rejection list showed "earnings date unknown — BMNR ×7, EWZ ×5" two weeks
after v1.1.292 exempted ETFs from the earnings gate, and read as a live fault. Checked: all five EWZ
rejections predate the exemption (shipped 2026-09-19 16:04 ET), and EWZ was picked on 2026-09-30, so
the exemption works. BMNR is a stock with no calendar date, failing closed as designed.

**Cause.** The rejection tallies are cumulative since the first shadow run (2026-09-14) and record no
rule version. v1.1.299 solved this for the leg rules by re-judging each stored missing-leg rejection
under today's band; nothing did the same for the earnings gate.

**Change.** Each earnings-gate refusal — "earnings date unknown", "earnings calendar stale (…)",
"earnings DATE on/before every … expiry" (`isEarningsRejection`) — now carries a cause from
`judgeEarningsRejection`, decided on today's ETF membership: **"an ETF — exempt from the earnings gate
since v1.1.292"** or **"not an ETF — the gate still applies"**. It reaches the report through the same
`causes` field the leg diagnosis uses (type widened from `LegCause` to `RejectionCause`), so the script
and the 🪜 Spread Shadow view show it without changes.

Tests (`tests/spread-mode-settle.test.ts`, +3): the three earnings refusals recognised and nothing
else, both verdicts, and the report splitting an EWZ/BMNR line into 3 exempt and 2 still gated.
