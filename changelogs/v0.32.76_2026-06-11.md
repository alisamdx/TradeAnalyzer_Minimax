# v0.32.76 — 2026-06-11

## Fix: Polygon fundamentals plan restriction surfaced instead of silently skipped

### Root cause

`/vX/reference/financials` (Polygon's financial statements endpoint — income statement,
balance sheet, cash flow) is restricted to the **Developer plan ($199/mo)** and higher.
The current subscription is **Stocks Starter**, which returns HTTP 403.

**Why it only appeared with the orchestrator:**

The fundamentals cache has a 24-hour TTL (`TTL_SECONDS.FUNDAMENTALS = 86_400`
in `cache-service.ts`). All prior manual market-sync runs were done within 24 hours of
each other, so `FundamentalsCache.isStale()` always returned `false` → `getFundamentals()`
was never called → the 403 never surfaced. The orchestrator's strict daily schedule is
the first code path that reliably runs with a stale fundamentals cache, triggering a live
Polygon call and exposing the plan restriction.

### Previous behavior (v0.32.75)

- A 403 from the fundamentals endpoint was silently skipped per-ticker (same treatment as
  delisted/OTC tickers that 404).
- Fundamentals data was missing for every ticker with no indication in the job notes.

### New behavior (v0.32.76)

```typescript
// screener-service.ts — syncUniverse()
let fundamentalsPlanRestricted = false;

if (!fundamentalsPlanRestricted) {
  try { ... }
  catch (err) {
    if (err.message.includes('Polygon HTTP 401')) throw ...;
    if (err.message.includes('Polygon HTTP 403')) {
      fundamentalsPlanRestricted = true;  // stop calling fundamentals for this run
    }
    // other errors: silently skip per-ticker
  }
}

const notes = fundamentalsPlanRestricted
  ? 'Fundamentals skipped — /vX/reference/financials requires a Polygon Developer plan or higher (current plan: Stocks Starter).'
  : undefined;
return { scanned: total, notes };
```

- On first 403: set `fundamentalsPlanRestricted = true`, stop calling the fundamentals
  endpoint for all remaining tickers (~1000 skipped round-trips avoided).
- Quotes continue to sync normally.
- Job status: `success` with notes string visible in Batch Jobs → run history.
- `market-sync-job.ts`: appends notes to the job result notes field.

### Files changed

- `src/main/services/screener-service.ts` — `syncUniverse()` return type now

- `src/main/services/jobs/market-sync-job.ts` — appends `result.notes` to job notes
