# v1.1.82 — 2026-06-25

## Fix: Pre-Trade Validator suggestion recommended a pin-bet butterfly for a wheel

### Symptom
Validating a held NVDA 185 CSP (ownership intent) — correctly flagged CAUTION for a thin
cushion — the **LAB SUGGESTS INSTEAD** block proposed:

> Put Butterfly (grade A) — buy put $190 · sell put $185 · buy put $170
> "Lab's best ownership fit: Put Butterfly…"

A put butterfly is a **neutral pin bet** (max profit only if the stock lands near $185 at
expiry; you never acquire shares). It is not an ownership/wheel structure, so it's a wrong —
even misleading — "better structure" for that intent.

### Cause
`pickSuggestedStructure`'s ownership filter was `isCredit(s) && s.slug.includes('put')`.
`put-butterfly` contains "put" and (as a credit/broken variant) passed `isCredit`, so a
high-grade butterfly outranked the real wheel structures.

### Fix
`src/main/services/pretrade-checks.ts` — the suggestion picker now:
- **Globally excludes pin-bet butterflies** (`put/call-butterfly` + broken-wing/heart variants)
  from every intent's pool — they express no directional/ownership thesis.
- Uses **explicit per-intent slug allowlists** instead of substring matching:
  - ownership → `short-naked-put`, `short-put-vertical`
  - income → `iron-condor`, `dynamic-width-iron-condor`, `iron-fly`, `short-strangle`,
    `short-straddle`, `short-put-vertical`, `short-call-vertical` (and must be a credit)
  - directional → bull/bear categories
  - hedge → `long-put*`, `poor-mans-covered-put`

### Tests
`tests/pretrade-checks.test.ts` (24): ownership never suggests a butterfly even at higher grade;
directional skips a pin-bet butterfly in favor of a real vertical.

### Note
This came out of the validator try-and-tune loop — the *checks* on NVDA were all correct
(cheap-vol → info as an owner, bullish-against-trend → info, thin-cushion → the one real warn);
only the downstream suggestion needed tightening.
