# v0.22.13 — 2026-06-01

## Daily Brief — Payoff, Validate, and Options quick-nav buttons on pick cards

Each pick card now has a compact row of three navigation buttons that
deep-link directly from the brief into the relevant view, pre-populated
with the ticker and strategy details from the most recent Strategy Lab run.

### Buttons

| Button | Navigates to | Pre-populated |
|--------|-------------|---------------|
| 📊 **Payoff** | Payoff Visualizer | Ticker, spot price, expiry, best-scoring strategy slug, and all option legs from the Strategy Lab setup |
| ✓ **Validate** | Validate tab | Ticker |
| 📋 **Options** | Options Chain | Ticker + expiry date from the best strategy setup (when available) |

### Example (TSCO — Wheel pick, CSP B grade)

```
📊 Payoff   ✓ Validate   📋 Options · 2026-07-18
```

Clicking **Payoff** opens the Payoff Visualizer with the Short Naked Put legs
already loaded at the CSP strike/expiry/premium from Strategy Lab.

Clicking **Options** opens the Options Chain pre-filtered to the `2026-07-18`
expiry that Strategy Lab used — saving the manual expiry hunt.

### Implementation

- `labLegToPayoffLeg()` — converts `SetupLeg` → `PayoffLeg` for the nav event
- `PickNavRow` component — reads `pick.strategyLabResult.scores[0].setup` for
  expiry and legs; dispatches `navigate-to-payoff`, `navigate-to-validate`,
  `navigate-to-options` CustomEvents already listened to in `App.tsx`
- `.pick-nav-row` / `.pick-nav-btn` CSS added
