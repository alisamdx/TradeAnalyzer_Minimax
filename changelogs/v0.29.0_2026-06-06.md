# v0.29.0 — 2026-06-06

## Phase 1: Cross-pollinate Agent ideas into Daily Brief

Five improvements from the Agent's feedback-loop mechanics applied to the Retrospect / Daily Brief system.

### 1a — Option P&L stop (Low effort, Medium impact)

Retrospect now raises a **Close Signal** when the estimated option P&L falls below **-(2× entry premium)**, regardless of the underlying stock % move. Previously the close heuristic was stock-price-only, which missed losses driven by IV expansion or theta underestimate. Mirrors the Agent's unrealized P&L stop logic.

Changed: `paper-trading-service.ts` — `getOpenPositions()` and `computeInsight()` both check `estimatedPnl < -(entryPremium * 2)`.

### 1b — Gap cause classification (Medium effort, High impact)

When a paper trade closes, `captureCloseLearning()` now instructs Claude to return a **structured `gapCause`** field alongside the narrative:
- `IV_CRUSH`, `TREND_REVERSAL`, `EARNINGS_GAP_RISK`, `THETA_UNDERESTIMATE`, `EARLY_CLOSE_MISSED`, `MODEL_ERROR`

The cause is validated against the enum and stored in `learning_json`. A color-coded badge is shown in the **Retrospect → History** tab next to each closed trade.

New type: `TradeLearningGapCause` in `shared/types.ts`.

### 1c — Pattern recommendations (Medium effort, High impact)

After each learning capture, `checkForPatternRecommendations()` queries all closed trades for the same strategy + gap cause. If the count reaches **≥ 3**, a recommendation row is upserted into the new `brief_learning_recommendations` table (migration 032). The recommendation includes a plain-English description and a specific proposed tweak. These appear as cards in **Retrospect → Summary** tab under "Pattern Recommendations".

New migration: `migrations/032_brief_learning_recommendations.sql`

### 1d — Exit plan per pick in Brief PDF (Low effort, Medium impact)

Each pick card in the PDF attachment now includes an **Exit Plan** section:
- Target close at **50% of max profit**
- Stop loss at **2× max loss**
- Suggested hold DTE: **50% of DTE at entry**

Changed: `brief-report-builder.ts` — `buildPickCard()` and `estimateCardHeight()`.

### 1e — Signal weight suggestions (Medium effort, Very High impact)

`ScoringService.computeSignalCorrelations(strategy)` computes **Pearson r** between each signal's score contribution and Day+1 positive outcomes (from `paper_trade_snapshots`). Returns a `SignalWeightSuggestion[]` with current weight, correlation, suggested weight, and direction (increase / decrease / hold).

Exposed as `scoring:signal-correlations` IPC and `window.api.scoring.signalCorrelations()`. A new **"Signal Correlation Suggestions"** table is shown at the bottom of **Trade Scoring Config**, with color-coded correlation and suggested weight per signal. Needs ≥ 10 snapshots — shows an informational message until then.
