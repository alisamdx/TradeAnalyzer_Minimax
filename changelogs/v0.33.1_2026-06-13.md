# v0.33.1 — 2026-06-13

## Bearish inflection — both directions complete

The Inflection strategy now trades both sides of a breakout: up-breaks → bull put spread
(shipped v0.33.0), down-breaks → bear call spread (this release).

### What

- **`hasBreakout` accepts `breakout_state === ±1`** — fresh with-trend down-breaks (20-day-low
  break below SMA50) now score and surface, mapped to `short-call-vertical` (bear call spread).
- **Direction-aware Brief Replay** (the prerequisite): migration 042 adds
  `replay_outcomes.direction` (1 long / −1 short). Populated per pick in the replay run from
  the breakout sign (`signalMap[ticker].breakoutState`); bearish = −1, all others = 1. Legacy
  rows are NULL and fall back to the strategy-implied direction, so old data still aggregates
  correctly.
  - **Win/hit-rate** (`getSummaries`) now uses `COALESCE(direction, strategy-implied)` uniformly
    — a short pick wins when the stock falls.
  - **Average return**: direction-adjusted for inflection only (`AVG(direction × ret)`, positive
    = thesis worked) so long and short picks don't cancel; the other five keep their raw average.
  - **Charts** (`getChartData`): inflection's 21-day return is direction-adjusted in SQL, so the
    rest of the chart math treats it as a long strategy (rev = false).
- **Critic structure selection**: for inflection, `selectRelevantStructure` now picks the
  **higher-graded** of the two relevant verticals. The lab's 90-day direction bias makes the
  correct one grade higher (bull put on an up-break/uptrend, bear call on a down-break/downtrend),
  matching the brief card's existing best-score selection (`gradeOf`).

### Notes

- The strategy is direction-agnostic in *ranking* (it scores breakout quality); the *direction*
  comes from `breakout_state`, the *structure* from the higher-graded vertical, and the *outcome*
  from `replay_outcomes.direction`.
- Re-run Brief Replay to populate `direction` and see the inflection bull/bear split.

### Tests

- `tests/replay-direction.test.ts` (2): a down-pick that fell counts as a win and one that rose
  as a loss; direction-adjusted average; legacy bearish (NULL direction) still aggregates via
  fallback with raw average preserved.
- `tests/inflection-scoring.test.ts`: updated — a down-breakout now scores > 0 (was 0 in the
  bullish-only phase). Suite: 295 passing.
