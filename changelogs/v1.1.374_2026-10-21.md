# v1.1.374 — 2026-10-21

## TradeAnalyzer 2: accepted findings no longer make a run RED

`core` 0.6.82, `next` 0.4.67.

### What was wrong

`runGate` added each fired finding to `counts.blocking` / `counts.warning` by its resulting severity, whatever its state, and took the verdict from those counts. Three other readers count only `open` and `acknowledged` findings:

- the email subject (`blockingThisRun` in `qa/email.ts`);
- `recomputeDomainDayStatus` (an accepted finding makes its domain-day usable, 03 §5.1);
- the clean-day streak.

So the gate's own number disagreed with all three. In the 2026-10-20 rehearsal the gate said 21 blocking and the subject said 11. The difference was QC-603 ×7 (accepted until 2026-12-15) and QC-204 ×3 (accepted until 2027-01-05), all still firing. It did not change that night's result, since the 11 open findings made it RED anyway. But a night on which only accepted findings fired would have been recorded RED in `qa_quality_report.overall` and the batch note, with an email subject of "RED (0 blocking)" and every domain-day usable.

### Change

- `upsertException` returns the finding's state along with its severity.
- `runGate` counts a fired finding toward the verdict and `blocking` / `warnings` only when it is `open` or `acknowledged`. Every other fired finding (`accepted`, `expired_review`) goes into the new `GateResult.tolerated`. Nothing about the findings themselves changes: they are still upserted, still marked firing, and still shown in the email's accepted section.
- `DailyRunReport.tolerated` carries it through. TA1's collector-daily batch note adds ", N accepted still firing" when it is non-zero, and `rehearse-gate.mjs` prints it.
- 03 §4: the `overall` definition now names the states it counts.

### Verification

- New tests in `gate.test.ts`:
  - an accepted finding that fires gives `green` / 0 blocking / 1 tolerated, and the email subject has no RED;
  - the same holds for `expired_review`;
  - an acknowledged finding that fires still counts as blocking and RED.
- Core suite: 792 tests passing. Root typecheck clean. Collector host/job tests passing.
