# v0.23.10 — 2026-06-05

## fix: Daily IV Update processes only ~10 tickers on second run of the day

Root cause: the job filtered out tickers that already had a row in iv_history for
today. After the 10 AM run populated 1057 rows, the 6 PM run found only the 10
leftover dot/no-options tickers and finished in 8 seconds with 0 updates.

Fix: removed the "already done today" filter. The job now re-processes all universe
tickers on every run. iv_history uses ON CONFLICT DO UPDATE so re-running safely
overwrites today's row with the latest ATM IV value — enabling accurate intraday
IV tracking.
