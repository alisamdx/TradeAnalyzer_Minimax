# v0.22.14 — 2026-06-01

## Fix: Payoff Assess Trade — AI was reading year as DTE

The AI assessment prompt passed `expiry 2026-07-17` with no explicit DTE value.
Claude picked up `2026` as the DTE figure, producing nonsense like
*"long 2026 DTE provides ample theta runway"*.

### Root cause

`payoff-service.ts` built the legs description with only the ISO expiry date
string — no computed DTE. The model's best guess for the number of days
remaining was the year component.

### Fix

DTE is now computed server-side from `leg.expiry` and appended inline:

```
expiry 2026-07-17 (45 DTE)
```

### Files changed

- `src/main/services/payoff-service.ts` — compute DTE per leg in prompt builder
- `package.json` — version 0.22.14
