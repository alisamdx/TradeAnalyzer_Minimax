# v0.32.89 — 2026-06-12

## Brief Replay

New screen under the Intelligence section (sidebar: ⏪ Replay) for back-testing the 5-strategy scoring pipeline against historical dates.

### How it works

1. User picks a from/to date range and clicks Run.
2. All existing replay data is cleared.
3. For every NYSE trading day in the window, the service:
   - Computes point-in-time signals from `historical_prices` and `iv_history` (price loaded once into memory, sliding window per date).
   - Fundamentals come from `fundamentals_cache` (current data, not point-in-time — acceptable for v1).
   - Calls the production `ScoringService.scoreFromSignalData()` with live configs so config changes are reflected immediately.
   - Applies Option A liquidity proxy: `avgVolume20d ≥ 1,000,000 AND price ≥ $5`.
   - Persists top-5 picks per strategy to `replay_briefs` + seeds `replay_outcomes`.
4. After the scoring loop, `evaluateOutcomes()` fills 5d/10d/21d forward returns from `historical_prices`.

### Signals computed for replay

| Signal | Available |
|---|---|
| `lastPrice`, `smaStack` (20/50/200), `priceMomentumPct` | ✅ |
| `rsi` (14-period Wilder smoothed) | ✅ |
| `recentVolatility` (20d annualized realized vol) | ✅ |
| `relativeStrengthVsSpy` (90d excess return vs SPY) | ✅ |
| `sectorMomentumPct` (90d sector ETF return) | ✅ |
| `ivRank` (from `iv_history`, 252-day window) | ✅ (if history loaded) |
| Fundamentals: `epsGrowth`, `revenueGrowth`, `roic`, `fcfToNetIncome`, `netDebtToEbitda`, `revenueGrowth5Y`, `epsGrowth5Y` | ✅ (from cache) |
| `trendStrengthAdx`, `buySignalScore`, `annualizedReturn`, `optionLiquidityScore` | ❌ skipped |
