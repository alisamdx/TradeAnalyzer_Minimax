# v0.32.72 — 2026-06-11

## Orchestrator schedule slots UI

### What changed
The Orchestrator Edit modal now has a real slot manager instead of a note telling you to edit raw JSON.

### Before
A small grey note read: *"Schedule slot times (e.g. '10:15', '16:30') are stored in config_json.scheduleSlots — edit via the raw config editor."*

### After
- **Slot list** — all configured slots shown with a ✕ remove button each.
- **Add slot** — HH:MM input field + `+ Add` button (also accepts Enter). Auto-sorted on add.
- **Validation** — rejects non-HH:MM format, out-of-range hours/minutes, duplicates.
- **Schedule column** in the jobs table now displays the orchestrator's actual `scheduleSlots` array (e.g. `10:15, 16:30 ET`) instead of the unused `dailyScheduleTime` fallback.
