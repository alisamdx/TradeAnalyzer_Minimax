# v1.1.28 — 2026-06-16

**General expiry-payoff evaluator for structure P&L** — fixes a class of bugs the defined-risk/directional preferences (v1.1.25/27) surfaced by promoting structure types the original audit never examined (long verticals, butterflies).

## The bugs

`classifySingleExpiryPnl` classified structures by leg signature, which only priced 2-leg credit verticals correctly:

1. **Long (debit) verticals → negative max profit + wrong breakeven.** `width = (putSell.strike − putBuy.strike)` assumes the short leg is higher (credit orientation). For a *long* put vertical the bought leg is higher, so width went negative: GPN `long-put-vertical` reported `maxProfit = −698.75` (should be +301.25) and breakeven 64.49 off the short leg (should be 65.51 off the long leg). EL likewise. This also tanked their premium score (negative reward/risk), **under-grading exactly the directional verticals v1.1.27 prefers.**

2. **Butterflies → max loss understated 5–30×.** A 3-leg fly fell through the 2-leg put-spread branch (third leg + `qty 2` body ignored). Worse, the lab builds **broken-wing** flies (unequal wings), which have an uncovered short between the wings — so the true max loss is `(widerWing − narrowerWing)·100 + debit`, far more than the debit. ARE reported `maxLoss = −$8.75` (true **−$258.75**); FLUT `−$115` (true **−$615**). The *true* max loss was even sitting in the `maxProfit` field as a negative number.

3. **Degenerate condor wing.** ASTS's "iron condor" was built sell-call \$100 / buy-call \$100 (same strike — no further-OTM strike available): a zero-width, premium-less, protection-less wing. A mislabeled put spread.

## The fix

### Payoff evaluator (Findings 1 + 2)
`classifySingleExpiryPnl` now computes P&L from the **actual expiry payoff**: per-share P&L at price `S` = entry cash flow (`netCreditPerShare`) + Σ each leg's intrinsic (`dir·qty·intrinsic`). It samples every kink (0, each strike, a far point), takes max/min for max profit/loss, and finds zero-crossings for breakevens. Unboundedness is explicit: net-short calls → `maxLoss = null`; net-long calls → `maxProfit = null`; puts are always bounded (S ≥ 0). This prices verticals (both orientations), balanced **and broken-wing** butterflies, condors, lizards, and ratio/zebra structures correctly, and recovers breakevens the old code dropped (e.g. a big lizard's upper breakeven).

(Iron condors/flies and the calendar/PMCC diagonal branch are unchanged.)

### Honest debit reward/risk
The lab premium score for debit structures divided max profit by `netDebit`. For a broken-wing fly the true max loss exceeds the debit, so this overstated reward/risk. It now divides by `|maxLoss|` (= debit for a simple vertical; larger for a BWB), so the corrected risk flows into the grade.

### Degenerate-wing guard (Finding 3)
`buildSetup` now marks a structure unavailable when a same-side spread's long/short legs collapse to the same strike, instead of presenting a phantom wing.

## Scope / FR-SEY-5
