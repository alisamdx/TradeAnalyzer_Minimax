## Fixed

**Strategy Lab: stale E*Trade Greeks poisoned structures on thin chains** ([strategy-lab-service.ts](../src/main/services/strategy-lab-service.ts))

E*Trade returns correct option *prices* but months-stale *Greeks* on thin chains (every affected leg had OI = 0). Observed: WSO's $450 put claimed delta −0.50 ("ATM") while the stock traded at $375.66 — the put's $76.40 mid matched true deep-ITM intrinsic, proving prices were live while deltas were computed at a months-old spot.

`estimateUnderlyingPrice()` derived the lab's underlying from those deltas, so every structure was anchored to a phantom price. Tonight's damage: WSO (lab price 19.8% off → wheel put 11.8% ITM, critic flagged), AWI (31.4% off → income straddle struck $200 vs $152 spot, **critic passed it** — rank 1 income), MIDD (18.7% off, critic flagged), ALGM (6.6% off). 4 of 25 picks. The corrected premium signal (v0.32.67) surfaces high-premium names, which skews toward exactly these thin-OI chains — the two fixes interact.

Changes:
- `resolveUnderlyingPrice()`: spot priority is `chain.underlyingPrice` (E*Trade's real-time spot, always present in its chain response but previously unused; Polygon chains return null) → `DataProvider.getQuote()` → chain-delta estimate (last resort).
- Delta-sanity gate: if the delta-implied ATM strike deviates >8% from real spot, `trustDeltas=false` and `findByDelta` skips the delta path — leg selection uses moneyness offsets from the real spot.
- All three lab entry points (`validate`, `explore`, `getContext`) use the resolver.

**Critic prompt: side-aware `strikeOtmPct`** ([critic-service.ts](../src/main/services/critic-service.ts))
"positive = OTM" is only true for calls. AWI's broken straddle showed `strikeOtmPct +31.6%`, which the LLM read as a generous OTM cushion and passed. The prompt now defines the field as strike-vs-spot with explicit ITM/OTM semantics per side ("a short put with strikeOtmPct of +30% is deeply ITM and broken, not safe").

**Critic rule 11: `stale_lab_price`** (warning) — `|lab.underlyingPx − pick.price| / pick.price > 5%` → structures unreliable, do not trade as shown. Deterministic; would have caught all four picks tonight regardless of LLM verdict.
