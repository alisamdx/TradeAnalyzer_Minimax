# v1.1.22 — 2026-06-15

## Morning Briefing market regime reads the real VIX

Completes the VIX migration started in v1.1.21. The brief job now sources VIX from E*Trade
into `quote_cache`, and the critic reads it there — but the Morning Briefing dashboard had a
*second* VIX consumer still on the broken path.

`BriefingService.getMarketRegime()` fetched VIX via `dataProvider.getQuote('VIX')`, which
hits Polygon's *stocks* snapshot. VIX is an index (`I:VIX`), so that call always returned
null — the dashboard's `vixLevel` was permanently "normal" and `vixValue` null, and each
call wasted a rate-limited Polygon request.

It now reads VIX from `quote_cache` (the E*Trade-sourced value written by
`refreshVixQuote()`), classifying low (<15) / normal / high (>25) from the real number. Both
VIX consumers — the critic and the Morning Briefing — now use one source.

### Files

- `src/main/services/briefing-service.ts` — `getMarketRegime` reads VIX from `quote_cache`
  instead of `dataProvider.getQuote('VIX')`; drops the wasted rate-limiter acquire.
- `tests/briefing-service.test.ts` — new (+3): VIX read + level classification from
  `quote_cache`, and a guard that `getQuote('VIX')` is never called.
