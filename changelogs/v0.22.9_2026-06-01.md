# v0.22.9 — 2026-06-01

## Daily Intelligence Brief — UI redesign

Full visual overhaul of `DailyBriefView`. Previous layout had no CSS at all — signal labels, scores, and badges were unstyled inline text with no spacing.

### Changes

**`src/renderer/src/styles.css`** — Added ~200 lines of brief-specific CSS:
- Strategy sections: bordered rounded cards with collapsible header bar (emoji prefix, pick count pill, chevron)
- Pick cards: two-column grid (rank bubble | content); rank shown in circular badge
- Pick header row: ticker (large/bold) · score badge (color-coded bg: green ≥75, amber ≥55, red <54) · Validated chip · Strategy Lab → button (right-aligned)
- Signal chips: pill with muted label + bold value, human-readable names (IV Rank, Fundamentals, 52w Momentum, etc.)
- AI rationale: italic, left-border accent, proper line height
- Header toolbar: date meta, stale warning badge, History toggle, Run Now button
- History strip: date pill buttons with active state

**`src/renderer/src/views/DailyBriefView.tsx`**
- `SIGNAL_LABELS` map — converts raw signal keys to readable names (IV Rank, Prem Yield, Trend Strength, Buy Signal, etc.)
- `fmtRaw()` — smart value formatting per signal type (%, +/- momentum, /10 liquidity)
- `TopSignals` — chips now show `<label> <value>` side-by-side; shows top 4 (up from 3)
- `PickCard` — restructured to two-column grid with `pick-rank-col` + content div
- Score rendered as colored-background badge (`scoreBg` + `scoreColor` pair)
- Strategy label emojis added (🎡 🐂 🐻 💰 📈)

### Files changed

- `src/renderer/src/styles.css` — added brief styles
- `src/renderer/src/views/DailyBriefView.tsx` — redesigned layout + formatting helpers
- `package.json` — version 0.22.9
