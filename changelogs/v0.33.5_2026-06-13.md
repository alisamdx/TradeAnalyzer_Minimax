# v0.33.5 — 2026-06-13

## My Stocks — in-play flag + email

Two additions to the My Stocks (Conviction) view:

### In-play flag
- Migration 043 adds `conviction_stocks.in_play` (INTEGER, default 0).
- ConvictionService: `inPlay` on ConvictionStock (list + get); `setInPlay(ticker, on)`
  toggles it. Transient marker — NOT written to conviction_band_history.
- View: a 🚩 toggle column (flagged rows highlighted; header shows an in-play count).
  Optimistic flip on click.

### Email my stocks
- `ConvictionService.buildEmailReport()` renders the list as an HTML table with the
  flag, sorted in-play first then by zone; omits the Actions column (UI-only).
- Sent via the existing EmailService (SMTP from Agent Config → Email). New IPC:
  conviction:send-email, conviction:email-configured, conviction:set-in-play.
- '✉ Email My Stocks' button (disabled + tooltip when SMTP not configured).

Tests: conviction-in-play.test.ts (4) — flag default/toggle/persistence, no band-history
on toggle, email report includes flag + skips Actions + sorts in-play first. Suite 303 passing.
