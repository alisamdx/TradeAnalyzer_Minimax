# v1.1.53 — 2026-06-18

## Risk-budget spread width enabled (FR-SEY-5 validated) + Execution Settings controls

The default-off budget-width infrastructure (v1.1.52) is now **validated and enabled**. The liquidity
gate stays off (can't be backtested).

### Validation (FR-SEY-5)
`scripts/fr-budget-width-study.mjs` — a faithful replica of `BacktestEngine.simulateSingleSpread`
run over **1,386 inflection replay picks**, comparing two hedge-leg policies on the **same 0.30Δ
short strike and the same picks** (only the wing width differs):

- **CURRENT** — 0.15Δ protective wing (today's lab + backtest).
- **BUDGET** — widest wing whose per-contract max loss fits the per-trade budget.

At the operative **$500** budget (5% of $10k), paired on the 1,382 picks resolved under both:

| metric | current | budget |
| --- | --- | --- |
| return / max-loss | 5.6% | **6.1%** (Δ +0.5 pts) |
| win rate | 75.0% | 75.1% |
| sizeable at $500 | 58% | **100%** |

Narrower spreads carry a higher credit/max-loss ratio on wins, so return-on-capital is **neutral-to-
better** while **100%** of picks become sizeable (vs 58% today — the missing 42% are the high-priced
names like AMAT the engine currently can't trade). Sensitivity: **+0.9 pts** at $250, **−1.2 pts** at
$1,000 (wider budget → wider spreads → lower efficiency; the 5% per-trade cap keeps the budget small).
At worst neutral per FR-SEY-5 → shipped enabled (migration **055**, preserves a user override).

### Liquidity gate stays OFF (recorded finding)
`max_combo_spread_pct` (v1.1.52) remains 0. It **cannot be validated on the historical sample** —
there's no stored bid/ask to compute a combo relative spread — so per FR-SEY-5 it ships disabled.
The live Phase 7 AMAT round-trip crossing ~23% of the credit is the real-world rationale; enable it
(~0.20) manually in Execution Settings if desired.

### UI
**Execution Settings → Entry policy** now has **Risk-budget spread width** (toggle, on) and **Max
combo spread (rel.)** (number; 0 = off). Both flow through the existing `getConfig`/`updateConfig`.
