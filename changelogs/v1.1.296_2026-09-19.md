# v1.1.296 — 2026-09-19

TradeAnalyzer only.

## The bull put spread's numbers are editable in Settings → Strategies

Until now the operator's answers lived in code: `maxLossPerPosition` became $2,500 in v1.1.293 and the 3-per-sector cap was a profile constant. Changing either meant a rebuild. A new **Strategies** tab in Settings holds them:

- **Mode** — `shadow` or `off`. `on` is deliberately not offered: it is built when the 08 §4 gate passes, and showing it would imply the mode can be traded today.
- **Max loss per position** ($50–$1,000,000), **max open positions** (1–100) and **max open per sector** (1–100), each with a note on what it does; the screen shows the worst case (max loss × max open) as you change it.

### One writer, and it clamps

`writeSpreadModeSettings` (`spread-mode.ts`) is the only path that stores these. It rounds, clamps to `SPREAD_MODE_LIMITS`, falls back to the default on a non-finite number, refuses an unknown mode, and **never stores a sector cap above the position cap** — a cap that cannot bind would read as a rule that is on but silent. It returns what it stored, and the screen renders that rather than what was typed, so a clamped value is visible immediately ("some values were adjusted to their allowed range"). This is the conviction-band lesson: the invariant belongs in the choke point every writer passes, not in the form.

`maxOpenPerSector` is now a stored setting (`bullPutSpreadMaxOpenPerSector`), and the shadow report reads the cap from it instead of the profile constant.
