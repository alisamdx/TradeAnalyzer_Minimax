### Migration 048

Exit-policy config on `exec_config`: `stop_multiple` (2× credit), `defensive_dte` (2),

+ `close_reason` for exit proposals.

### `exit-policy.ts` — `ExitPolicy.evaluate` (pure)

Priority-ordered rules; first triggered wins (§3.3):

1. **Stop** — loss ≥ `stop_multiple` × credit → **protective** (auto).
2. **Defensive expiry** — DTE ≤ `defensive_dte` → **protective** (auto).
3. **Profit target** — mark ≤ credit × (1 − `profit_target_pct`/100) → **discretionary**.
4. **Planned/time exit** — held ≥ `hold_days` (or DTE ≤ `time_exit_dte`) → **discretionary**.

Priced rules (stop/profit) skip when the mark is unknown.

### `position-manager.ts` — `ManagementLoop`

- **`runOnce(now)`**: evaluates every open position; **protective → auto `submitClose`**;
  **discretionary → auto-close if mode is `auto`, else raise an exit proposal** (one pending
  per position). Audited (`exit_fired` / `exit_proposed`).
- **`approveExitProposal(id, now)`**: closes the position on approval.
