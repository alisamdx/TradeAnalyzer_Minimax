# v0.32.56 — 2026-06-09

## Fix: sectorMomentum SIC mapping + leverageQuality fallback + funnel logging + score tooltip

### Changes

**`src/main/services/scoring-service.ts`**

1. **`sectorMomentum` null rate fixed** (was ~50% null for tech-heavy universe)
   - Root cause: `SECTOR_ETF` used GICS names ("Technology") but `fundamentals_cache.payload_json.sector` stores Polygon's lowercase SIC descriptions ("electronic computers", "semiconductors & related devices", etc.)
   - Fix: added `sectorStringToEtf(raw: string): string | undefined` function using regex keyword matching on the SIC description
   - Coverage: ~0% GICS exact-match → ~58% SIC keyword match across 1,067 tickers in `fundamentals_cache`
   - In `loadSectorMomentum`: `SECTOR_ETF[row.sector] ?? sectorStringToEtf(row.sector)` — exact lookup first for backward compat
   - Affects `sectorMomentum` (bullish weight 5, buy weight 4) and `sectorWeakness` (bearish weight 7)
   - Known: GOOGL/META map to XLK (SIC says "computer programming") instead of XLC — XLK/XLC are highly correlated; acceptable approximation

2. **`leverageQuality` fallback to `debtToEquity`**
   - Root cause: `netDebtToEbitda` has only ~9% coverage (97/1067 non-null) in Polygon fundamentals
   - Fix: in `loadFundamentals`, when `p.netDebtToEbitda` is null, fall back to `p.debtToEquity * 2.5`
   - Coverage: 9% → ~30% (321/1067 have `debtToEquity`)
   - Affects `leverageQuality` (wheel weight 4) and `leverageRisk` (bearish weight 6)
   - Approximation comment added: `// D/E 1.0 ≈ ND/EBITDA 2.5 for non-financial companies`

**`src/main/services/jobs/daily-intelligence-brief-job.ts`**

3. **Brief funnel log added**
   - After liquidity gate per strategy: `console.log('[brief funnel] {strategy}: {n} pre-gate → {m} final (gated: TICKER1, TICKER2)')`
   - Diagnostic only — no behavior change
   - Purpose: distinguish "liquidity gate is too aggressive" from "genuine candidate scarcity" (e.g. income with only 2 picks)

**`src/renderer/src/views/DailyBriefView.tsx`**

4. **Score badge tooltip**
   - Added `title` + `cursor: help` to `pick-score-badge` span
   - Text: `"Composite score: {N}\nScores are strategy-specific — not comparable across strategies (each uses different signals and weights)."`
