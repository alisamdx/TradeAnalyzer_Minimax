# v0.30.1 — 2026-06-07

## Portfolio Greeks — ENH-3

Implements the live-Greeks fetch path so the Portfolio Greeks bar works for
manually entered CSP/CC positions, not just E*Trade-synced ones.

### "⚡ Refresh Greeks" button
Appears in the Greeks bar row (Portfolio → Open Positions tab).
Calls `portfolio:fetchGreeks` IPC which:
1. Lists all open CSP/CC positions with a strike and expiry
2. Groups by (ticker, expiry) → one `optionsProvider.getOptionsChain()` call per group
3. Matches contract by `side` (CSP→put, CC→call) and strike (±$0.50 tolerance)
4. Applies short-position sign flip before storing: `storedDelta = -(chainDelta)`,
   `storedTheta = -(chainTheta)`, `storedVega = -(chainVega)`
   → short put: +delta, +theta, −vega (correct for premium seller)
   → short call: −delta, +theta, −vega
5. Writes to `positions.delta/theta/vega` columns (existed since prior migration)
6. Returns `{ updated, failed, errors }` → status toast in UI

### Greeks bar fallback
`greeksSummary` useMemo updated: for options positions not in `etMap` (no
E*Trade sync data), uses `pos.delta/theta/vega` instead of defaulting to 0.
E*Trade sync data still takes precedence when present.
