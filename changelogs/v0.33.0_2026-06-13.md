# v0.33.0 — 2026-06-13

## Inflection strategy — Phase 3: live in the Daily Brief

Completes the new Inflection strategy. It now surfaces in the live Daily Brief as a
6th strategy: a bullish **directional credit spread anchored at a fresh 20-day breakout**.

### What

- **`inflection` joins `STRATEGIES`** (the live brief set; was validated in Brief Replay
  only in v0.32.99). `REPLAY_STRATEGIES` now aliases `STRATEGIES` — replay and brief score
  the same 6.
- **Structure = `short-put-vertical` (bull put spread)** — the existing Strategy Lab credit
  vertical (sell put ~0.30Δ / buy put ~0.15Δ), defined-risk with correct credit P&L already
  in `buildSetup`. No new construction needed.
- **Wired through the brief pipeline**: `STRATEGY_RELEVANT_SLUGS.inflection =
  ['short-put-vertical', 'short-call-vertical']` (bull put first) drives the liquidity gate,
  critic structure selection, and the brief card. 6th section added to `DailyBriefView`
  (`STRATEGY_ORDER`) and the PDF/email report (`brief-report-builder`), with readable names
  "Bull Put Spread" / "Bear Call Spread" in `SLUG_SHORT`.
- **Fix**: v0.32.99 mapped inflection to non-existent `bull-put-spread`/`bear-call-spread`
  slugs; corrected to the real `short-put-vertical`/`short-call-vertical`.

### Behavior notes

- Inflection scores 0 without a fresh with-trend up-breakout, so it self-limits: 5 picks on
  active days, fewer (or none) on quiet ones.
- Picks only appear after `DailyTechnicalSignalsJob` has populated the migration-041 breakout
  columns (first nightly run post-upgrade); until then inflection scores 0 for all tickers.
- Not in the earnings penalty or a min-composite gate yet — both can be added after observing
  live behavior. Still bullish-only.

### Remaining follow-up

Bearish inflection (down-break → bear call spread): enable `breakout_state === -1` in

### Tests
