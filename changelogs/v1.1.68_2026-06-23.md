# v1.1.68 — 2026-06-23

## Critic liquidity caution aligned with the engine's tradability bar

### What the audit found
A real-money readiness deep-dive on the (healthy) after-close brief: the critic and the engine
disagreed about liquidity, and the critic was the lenient one.

- Engine entry gate (`brief-entry-source.hasAdequateLiquidity`): rejects a chosen structure with
  `liquidityScore < 8` **or** any leg with a `$0` bid.
- Critic `checkLiquidity`: only raised `low_liquidity` (info) when `liquidityScore < 4`.

So a defined-risk spread scoring **4–7** got a green "✓ Pass" from the critic, while the engine would
**reject** it. Today's inflection picks landed exactly there:
- **AEP** — rank 1, grade A, critic "✓ Pass: the setup is clean… reasonable 11.3% yield", **liquidity
  6/15** → the engine would reject it.
- **BALL** — short-put-vertical with a **$0-bid long leg** (52.5 put) — can't be reliably exited.
- **VIK** — liquidity 5/15.

A human trading the brief's displayed verdict could therefore enter illiquid spreads the engine
itself refuses — and the critic's yield/reward numbers used the (already fill-haircut) credit
without caveating that crossing a 64%-wide market bleeds a large share of it.

### Fix
1. **One shared threshold.** `MIN_TRADABLE_LIQUIDITY_SCORE = 8` now lives in
   `src/shared/strategy-structures.ts` and is imported by **both** the engine gate
   (`brief-entry-source`) and the critic (`critic-service`), so they can't drift apart (they had).
2. **Critic aligned for tradable spreads.** For a **defined-risk multi-leg spread** (legs > 1 and a
   finite `maxLoss` — what the engine trades), `checkLiquidity` now raises a **`warning`** when the
   chosen structure is below the bar, or has a no-bid leg. Warning severity so the verdict actually
   reflects it (a human sees the same liquidity wall the engine enforces). The old `< 4` info rule
   still covers single-name short-premium, where 4–7 is genuinely normal and should not preclude a
   pass.

With this, today's AEP/BALL/VIK would carry a liquidity warning → caution/flag, not a clean pass.

### Validation (FR-SEY-5)
Validation-exempt: the engine's liquidity gate (8) is **unchanged** — this only aligns the critic's
*display* caution to it. Strictly more conservative (the critic can only add caution, never remove
it). No change to selection, sizing, or exits.

### Files

- `src/main/execution/brief-entry-source.ts` — use the shared constant for the gate.
- `src/main/services/critic-service.ts` — `checkLiquidity` warns below the bar / on a no-bid leg for

- `tests/critic-service.test.ts` — 4 new tests (spread below bar → warning; at bar → none; no-bid
