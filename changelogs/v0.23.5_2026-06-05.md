# v0.23.5 — 2026-06-05

## fix: Strategy Lab "Insufficient option data at target delta" error

**Root cause**: Two filters in `findByDelta` (`strategy-lab-service.ts`) caused most
strategies to return unavailable when E*Trade didn't include Greeks in the chain response.

1. **`includeGreeks: 'true'`** added to E*Trade `/v1/market/optionchains` request
   (`etrade-options.ts`). E*Trade omits the `OptionGreeks` block by default outside
   certain conditions; this parameter ensures delta/gamma/theta/vega are always requested.

2. **Bid filter relaxed** from `bid > 0` to `bid >= 0` in `findByDelta`. A zero bid means
   no current market-maker quote, not that the contract is unusable — far-OTM or
   after-hours contracts were being incorrectly excluded.

3. **Moneyness fallback** added to `findByDelta`. When Greeks are genuinely absent
   (pre/post-market or illiquid ticker), the function now approximates target strike
   from `underlyingPx` × a moneyness factor derived from `targetDelta`, so strategies
   can still display a setup with best-effort pricing rather than showing the error.
