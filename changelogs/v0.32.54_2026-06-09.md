# v0.32.54 — 2026-06-09

## Feat: Brief Trend — click ticker to view 45-day candlestick chart

### What was added

**`src/renderer/src/components/BriefPriceChartModal.tsx`** (new)
- Modal overlay with lightweight-charts candlestick chart
- Fetches via `window.api.historical.getPrices(ticker, briefDate, briefDate+45d)` — no new IPC
- Overlays: dashed blue price line at briefPrice, 'Brief' arrowUp marker on the first bar (brief date), 'D5' arrowDown marker on rawBars[5] (Day 5 = 5th trading day after brief date)
- Fallback: shows error if fewer than 2 bars available
- Dismiss: Escape key or click outside the card
- Footer shows 5-day return (from the grid)

**`src/renderer/src/views/RetrospectView.tsx`** (modified)
- Added `import BriefPriceChartModal`
- Added `chartPick` state to `BriefTrendTab`
- Ticker span: `cursor: pointer`, dotted underline, `onClick={() => setChartPick(p)}`
- Title tooltip preserved: shows AI rationale + "Click to view 45-day chart" hint
- Renders `<BriefPriceChartModal>` when `chartPick` is set

### Design notes
- 45 calendar days chosen to cover the typical options expiry window (most CSP/wheel trades expire within 45 DTE)
- `historical_prices` only has market-open days, so the chart shows fewer than 45 bars — typically ~30 trading days in the window
- For recent briefs, the 45-day window is incomplete: the chart shows available bars through today (correct behavior)
- Day 5 marker uses rawBars[5] (index 0 = brief date, index 5 = 5th trading day after) — consistent with how getBriefPickDrilldown computes day prices via ROW_NUMBER()
