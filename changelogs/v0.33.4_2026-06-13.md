# v0.33.4 — 2026-06-13

## Brief sections ordered by the day's top composite score

The Daily Brief (screen + email + PDF) previously rendered strategy sections in a fixed
order (wheel→bullish→bearish→income→buy→inflection). They now sort by the **top composite
score per strategy** (highest first), so the day's strongest-scored pick's strategy leads.

- Shared helper `orderByTopComposite` in brief-report-builder.ts (HTML + PDF) and a mirror
  in DailyBriefView.tsx (screen). Sort key = max(pick.compositeScore) per strategy, desc;
  fixed STRATEGY_ORDER breaks ties and trails empty strategies.
- Caveat (documented in code + the existing score-badge tooltip): composite scores are
  strategy-specific, so this is a surfacing heuristic, not a cross-strategy quality ranking.
- Also fixed the PDF cover's hardcoded "across 5 strategies" to the actual strategy count.

Tests: brief-strategy-order.test.ts (3) — orders by top score, empties last in fixed order,
ties broken by fixed order. Suite: 299 passing.
