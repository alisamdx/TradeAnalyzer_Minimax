# v1.1.31 — 2026-06-16

## Critic cites a precomputed expected-move instead of computing it (brief accuracy audit)

### The bug
The Daily-Brief critic's LLM prompt handed the model the formula for the expected 1-sigma
move (`impliedVolPct × √(dte/365)`) and asked it to compute it. The model's manual arithmetic
was unreliable and **routinely overstated the move** on the 2026-06-16 brief:

| Pick | Critic's stated move | True (price × IV × √(dte/365)) | Error |
|---|---|---|---|
| AMD (wheel) | "±$149 (~29%)" | **±$104 (20.5%)** — 70.271% IV, 31 DTE, $507.29 | +43% |
| MRVL (bullish) | "~$152" | **±$82 (29.5%)** — 101.334% IV, 31 DTE, $278.67 | +85% |

(AMD's price/IV were confirmed against a live quote: $507.29, −7.30% on the day, market closed.)

This is the **same class** of error already removed from the critic's volatility context — when
the prompt told the model to "compute an expected 1-sigma move (annualized vol …)" with no vol
field, it *fabricated* IV numbers (v1.1.20); when it lacked the realized-vol signal it flagged a
phantom IV discrepancy (v1.1.29). The governing principle (`CLAUDE.md` Known quirks): *anything
the critic should reason about numerically must be in the context object, not derived by the LLM.*
The expected move was the last numeric the prompt still asked the model to compute.

### The fix
- New exported pure `expectedOneSigmaMove(impliedVolPct, dte, price)` in `critic-service.ts`
  returns `{ pct, usd }` (e.g. AMD → `{ pct: 20.5, usd: 103.89 }`), nulls when IV is
  missing/non-finite or DTE ≤ 0.
- `dte` is hoisted to the context-builder scope; the move is precomputed from
  `volatility.impliedVolPct`, the structure's DTE, and `pick.price`, and added to the volatility
  context as `expectedMove1SigmaPct` / `expectedMove1SigmaUsd`.
- The prompt's VOLATILITY section now tells the model to **cite the provided
  `expectedMove1Sigma*` numbers verbatim** and to NOT compute, derive, or estimate the move
  itself (its arithmetic has been unreliable); if absent, skip expected-move reasoning.

### Impact / validation
- **Rationale-accuracy only** — no rule check, gate, or trade selection changed; the
  deterministic rule layer never used the LLM's move estimate. The persisted 2026-06-16 brief
  keeps the old LLM-computed rationales; **re-run the brief** for the corrected figures.
- Regression tests in `tests/critic-service.test.ts`: AMD (±$104/20.5%), MRVL (±$82/29.5%),
  price-unknown (pct only), and null-IV / zero-DTE → no move. Full suite: **530 passing**.
