# v0.28.2 — 2026-06-06

## Agent screen — Trades tab: Close button, Action column, AI learning

### Removed
- **Today's Actions panel** at the top of the Trades tab — redundant with the dedicated Actions and Recommendations tabs

### Added — Action column
Every open trade row now shows a per-row **Action** badge (same logic as Today's Actions, now inline):
- 🔴 **Close / Roll** — ≤5 DTE or expiry imminent
- **Roll / Roll (ITM)** — ≤14 DTE with positioning notes
- **Defend** — stock is ITM
- **Monitor** — stock within 3% of strike
- **Take Profit** — ≥50% of premium captured
- **Hold** — no action needed

### Added — Close button
Each open trade row has a **✓ Close** button. Clicking it opens an inline close panel directly below the row with:
- Pre-filled reason based on the computed action (editable)
- Confirm Close / Cancel buttons
- Enter key submits, Escape cancels

### Added — AI learning capture
After confirming a close, Claude Haiku automatically generates a learning note (async, ~2-3s):
- **Strategy was sound** — yes/no
- **Key lesson** — one sentence on the main takeaway
- **Suggested tweak** — one sentence on what to change next time (if any)

Learnings are stored in the local DB (`agent_trade_learnings` table, migration 031) and appear in the expanded row detail. Learnings from previous sessions are loaded on view mount.
