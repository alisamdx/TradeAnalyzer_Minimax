# v0.32.40 — 2026-06-08

## Added

### Daily Brief auto-watchlist (`DailyBrief-MMDD`)

After each Daily Intelligence Brief job run, a watchlist named `DailyBrief-MMDD` (e.g. `DailyBrief-0608`) is automatically created or refreshed:

- If the watchlist already exists for today, all items are cleared and replaced with today's fresh picks.
- If it does not exist, it is created.
- All final post-gate picks from all 5 strategies are added as items.
- The notes field on each item shows which strategies selected that ticker (e.g. `wheel · buy`), providing context when viewing the list elsewhere in the app.

The watchlist is immediately available in Watchlists, Screener, Analysis, and anywhere else the app consumes watchlists — useful for running the screener against the brief's picks, loading them into the analysis engine, or reviewing them as a group.
