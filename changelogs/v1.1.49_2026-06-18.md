# v1.1.49 — 2026-06-18

## Fix: after-close batch run now overwrites the morning's partial price bar

### Context
Found during the iterative Daily Brief accuracy audit. The 2026-06-17 inflection brief surfaced 5 picks but all had low composites (max 50.2) and would have failed the v2 entry gate (`min_composite_score = 70`). The root cause was upstream data, not scoring.

### The two-run design
The batch orchestrator runs the full job chain **twice on a trading day**:
1. **≈10:15 ET** — ~45 min after the open, an intraday opportunity scan.
2. **≈16:30+ ET** — after close, the definitive end-of-day brief.

The 90-min `SKIP_WINDOW_MS` is only a mid-run resume guard, so the after-close slot correctly re-runs every job the morning slot ran.

### Root cause
The morning run stores a **partial** same-day daily bar — only the session-so-far volume and an intraday "close." `PriceGapFillJob` selected tickers to refresh with:

```sql
HAVING MAX(date) < date('now')   -- strictly before today
```

After the morning run, `MAX(date) = today`, so the test was false → the ticker was judged "fresh" → the **after-close run skipped it** and never overwrote the partial bar. Evidence: `historical_prices` for 2026-06-17 had `fetched_at = 10:19 ET` for every ticker, and the current-day bar held ~6–26% of each ticker's normal volume (the first ~50 min of the session).

### Impact
The evening technical-signals/brief pipeline then ran on the partial bar:
- **Breakouts fired on a non-final intraday close** (e.g. AMAT's breakout close $617.39 at 10:19 ET had faded to $592.92 by options-pricing time).
- **`volume_surge` read ~0.10–0.24** for every breakout candidate (today vol ÷ 20-day avg). Since `volume_surge` is 25% of the inflection composite weight (and normalizes against `normMax: 3`), this near-zeroed a quarter of the score — structurally capping inflection composites below the v2 `min_composite_score = 70` gate. The inflection-only execution engine would therefore never enter a trade.

### Fix
- **`PriceGapFillJob`**: removed the `MAX(date) < date('now')` staleness gate. The job now re-fetches the recent window (from `max_date − 3 days`) for **every** ticker with history on every run, and bootstraps tickers with no history. `historical_prices` is `INSERT OR REPLACE` on (ticker, date), so the finalized after-close bar overwrites the partial morning one. Bounded per ticker, so cost stays modest.
- **`paper_trade_snapshots`**: `ON CONFLICT DO NOTHING` → `DO UPDATE` for **today only** (past snapshots are final closes and stay immutable). The after-close run replaces the morning intraday snapshot with the finalized close.

### Batch-wide audit (per the "all jobs must refresh + overwrite" directive)
| Job → table | Same-day re-run | Action |
| --- | --- | --- |
| price-gap-fill → `historical_prices` | gate skipped today | **fixed → always re-fetch + REPLACE** |
| paper-snapshot → `paper_trade_snapshots` | `DO NOTHING` | **fixed → today `DO UPDATE`** |
| technical-signals → `technical_signals` | recompute + upsert | already correct |
| iv-capture → `iv_history` | `ON CONFLICT DO UPDATE` | already correct |
| options-premium-history → `options_premium_history` | `INSERT OR REPLACE` | already correct |
| brief → `daily_briefs` | new row per run (newest wins) | already correct |

### Recommended run times
- **Morning: 10:15 ET** is a good intraday-scan slot (45 min lets the opening auction settle). Treat its signals as provisional — they're built on a partial bar by design.
- **After-close: run late enough that the data provider's daily bar is *final*.** Polygon's same-day daily aggregate keeps settling for a while after the 16:00 close; **≈17:00 ET is safer than 16:30** for a fully-final bar. The overwrite fix only helps if the bar it fetches is the finalized one.

### Notes
- No scoring weights changed — this fixes the *data* the existing scoring consumes. With full-volume bars, `volume_surge` reflects real breakout participation and inflection composites can clear 70 on genuine high-conviction breakouts.
- New spec §20.5 documents the two-slot refresh+overwrite invariant.
- Regression test `tests/price-gap-fill-refetch-today.test.ts` (asserts a today-bar ticker is still scheduled). Full suite: **600 passing**, typecheck clean.
