# v0.34.0 — 2026-06-13

## Backtest integration — phase 2: aggregate 'backtest my picks'

Completes the backtest integration. Brief Replay can now run the option-P&L simulator
over every historical pick for a premium strategy, not one stock at a time.

- BacktestEngine.backtestReplayPicks(strategy): pulls every (date, ticker) pick for
  wheel/income from replay_briefs/replay_outcomes, simulates one CSP each via the
  IV-priced engine (simulateSingleCsp), and pools into AggregatePickBacktest — trade
  count, win rate, avg/median ROC, cumulative ROC, max drawdown, avg days held, and a
  cumulative-ROC equity curve by exit date.
- IPC backtest:replay-picks; preload backtest.replayPicks(strategy).
- Brief Replay summary table: a 💰 P&L button on the wheel/income rows opens a modal
  with the metrics + equity curve (recharts). Loading + error states included.

Each pick = one 0.30-delta / 30-DTE CSP, +50% profit / 200% stop, equal-weight, capital
unconstrained. This shows the REAL premium collected (option P&L), which the replay
summary's stock-return columns can't — directly addressing why premium strategies look
weak there.

Tests: backtest-iv.test.ts (+2) — aggregate simulates a CSP per pick and pools; empty
result when no picks. Suite 306 passing.
