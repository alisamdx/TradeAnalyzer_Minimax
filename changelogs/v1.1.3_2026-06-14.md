# v1.1.3 — 2026-06-14

## v2 execution subsystem — Phase 3a (headless core runtime)

The always-on engine that ties the risk governor and broker together into a running
loop. The control API + SSE that wraps it follow in Phase 3b. Still dormant — wired to
nothing yet.

### `market-hours.ts`

- **`isMarketOpen(date, { holidays })`** — DST-correct US equity-options regular hours
  (Mon–Fri 09:30–16:00 ET) via `Intl` (America/New_York); holidays passed in as a config
  set rather than hard-coded.
- **`etDateString(date)`** — the ET calendar date, used for the day-P&L anchor.

### `reconciliation.ts`

- **`reconcile(db, broker)`** (§2.9) — the broker is the source of truth. Syncs order
  status (by client order id) and position marks into `exec_*`, and detects drift:
  `unexpectedBrokerTickers` (broker holds, core doesn't) and `missingAtBroker` (core open,
  broker doesn't). Detection is separate from response so both are testable.
- **`markNeedsAttention(db, tickers)`** — flag affected open positions on a mismatch.

### `execution-core.ts` — `ExecutionCore`

Owns the broker + governor and runs the management cycle:

- **Cold-start reconcile-before-act** (`startEngine`): connect → reconcile → refuse to
  start on drift (flag positions, audit), else go running.
- **The cycle** (`runCycle`): skips when not running; **fails closed** on a disconnected
  broker; reconciles and **trips the kill switch** on drift; recomputes deployed capital;
  invokes the **market-cycle hook** (Phase 4 entry/exit policy) only while the market is
  open; updates the watchdog.
- **Health watchdog** (`getHealth`): broker-disconnected / stale-cycle degradation (§1.8).
- **Event stream** (`onEvent`): engine-state / cycle / health / reconcile-mismatch events
  for the SSE layer (3b).
- **Loop control** (`startLoop`/`stopLoop`) with an injectable clock for deterministic
  tests.
