# v0.32.88 — 2026-06-12

## Add: E*Trade + Analysis quick-nav on brief picks; E*Trade ticker links in the brief email

### Daily Brief view

Two new buttons on every pick card's quick-nav row (now: 📊 Payoff / ✓ Validate /
📋 Options / 🔍 Analysis / 🏦 E*Trade):

- **🔍 Analysis** — dispatches the existing `navigate-to-analysis` event (same one
  the screener uses), opening the Analysis view pre-loaded with the ticker.
- **🏦 E*Trade** — opens `https://us.etrade.com/e/t/invest/quotesandresearch?content=3&sym={ticker}`
  via `window.open` → the app's window-open handler routes external URLs to the
  system browser. Same deep-link pattern already used in the Opportunity screen.

### Brief email

Ticker symbols in the per-strategy tables are now hyperlinks to the same E*Trade
quote page, so the morning email jumps straight to the order screen. Link is styled
to keep the existing bold dark look (underline added so it reads as clickable).
