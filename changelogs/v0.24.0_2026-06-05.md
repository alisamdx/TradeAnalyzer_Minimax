# v0.24.0 — 2026-06-05

## feat: My Stocks — Conviction List (Phase 1)

Personal stock reference with price conviction bands. Single permanent list,
separate from watchlists. See Requirements/conviction-list.md for full spec.

### What's included

**DB (migration 026):**
- `conviction_stocks` table — ticker, price_low, price_mid, price_high, note, timestamps
- `conviction_band_history` table — audit trail written on every edit

**Backend:**
- `ConvictionService` — CRUD, band history, recommendation engine, sync from watchlist
- `ipc-conviction.ts` — IPC handlers for all operations
- Wired into `index.ts` alongside portfolio service

**UI (ConvictionView):**
- Table with Zone badge (✅ Buy Zone / 🟡 Mid Zone / 🔵 Watch / 🚫 Too High)
- Inline price band bar showing Low/Mid/High markers + current price indicator
- Add/Edit modal with 3 price fields + note textarea
- 💡 Get Recommendation button — derives suggested bands from existing analysis
  snapshots (entryZoneLow, SMA 50/200), quote_cache, and IV Rank. No new API calls.
  Apply individual bands or Apply All.
- Band History modal (🕓) — audit trail of previous band values
- Sync from Default Watchlist button — adds missing tickers with empty bands
- Sorted by zone (buy zone stocks float to top)
- Sidebar nav: ⭐ My Stocks in the Personal section

### Recommendation algorithm
- Low: entryZoneLow from buy analysis → SMA 200 → current −15%
- Mid: SMA 50 (if in range) → (low + current) / 2
- High: current × (1.20 / 1.25 / 1.30) scaled by IV Rank
