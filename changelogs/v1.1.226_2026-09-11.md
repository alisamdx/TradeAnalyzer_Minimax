# v1.1.226 — 2026-09-11

## Short interest: a placeholder in the URL, mistaken for a plan gap (`core` 0.6.2)

**What was believed.** Short interest was "the one §12 domain with no confirmed free source"
(02 §12, §16 item 5). Finnhub's endpoint is genuinely premium — 403, measured 2026-09-06 — and
Polygon's coverage was recorded as *unverified*. The dictionary carried a verify note on
`raw_short_interest.short_interest`, and that note is the last unmet condition on the pilot-exit
checklist: a generation cannot be promoted while any column's provider meaning is unconfirmed.

**What was actually true.** The collector asked for:

```
/stocks/vX/short-interest
```

`vX` is the documentation's placeholder, never replaced. Polygon answers that path with an 18-byte
body — `404 page not found`, which is exactly 18 bytes, matching the byte count recorded against the
failed call on the 2026-09-10 run. The real endpoint is `/stocks/v1/short-interest`, and Polygon's
documentation states it is **"Included in all Stocks plans"** (Basic, Starter, Developer, Advanced,
Business), updated every two weeks, with history to 2017-12-29.

The response fields Polygon documents — `ticker`, `settlement_date`, `short_interest`,
`avg_daily_volume`, `days_to_cover` — are precisely the columns `raw_short_interest` declares and
precisely what `ingestShortInterest` already reads out of `results[]`. **Nothing but the path
changes**: no parser, no dictionary, no capture rule.

### Why this went unquestioned for five days

The call failed exactly as an unentitled call fails. `meta_response` recorded a non-2xx with an
18-byte body, the phase reported `failed`, QC-904 fired with `days_since_settlement = 9999`
("never observed") — every one of those is also what a plan gap looks like. The prior belief
(Finnhub 403 the same week) supplied a ready explanation, and the spec then recorded the conclusion
as fact, wrong path and all: 02 §12 named `/stocks/vX/short-interest` in the sentence asserting the
coverage was unverified.

**A wrong URL and an unentitled URL return the same HTTP status.** A 404 is evidence about a *path*
before it is evidence about a *plan*, and the order matters: the cheap check is reading the path, and
it was never done.

### What is NOT done here

The verify note stays. Documentation is not a live response, and treating a document as evidence is
the error being corrected — the note clears when a real 200 returns rows for our tickers, which
Monday's 17:05 run will settle (the sentiment phase runs on a weekly cadence and is due). The
dictionary is unchanged at v13; `dictionary.test.ts` still asserts this is the one remaining note.

### Tests

`packages/core/test/provider-paths.test.ts` — no collector provider path may carry an unreplaced
`vX` / `vN` / `v{…}` placeholder; a fixture proves the scan fires rather than passing vacuously
(comments are stripped first, since this file's own discuss the placeholder); and short interest reads
the documented path.

FINRA was considered and set aside: its free downloadable file is the **OTC** equity file, the catalog
page is ambiguous about listed coverage, and the portal wants a login — a new parser and a coverage
study for a domain Polygon appears to serve already. It remains the fallback if the live call fails.
