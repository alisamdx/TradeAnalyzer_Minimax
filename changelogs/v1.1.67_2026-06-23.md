# v1.1.67 — 2026-06-23

## Critic fail-closed on AI failure + 529 retry (the "too many pass" deep-dive)

### What prompted it
A deep-dive on today's 10:15 (lean batch) brief: the operator saw *every* pick across every
strategy marked `✓ Pass` with 0 flags and `low` confidence — 21 uniform passes. That uniformity was
the tell. `daily_briefs.run_meta.aiError` held a **`529 overloaded_error`**: Anthropic was
overloaded, so both AI stages failed — Stage 5 (advocate, `aiRationale=null`) and Stage 5b (critic,
`rationale=null`).

### The bug
On LLM failure the critic falls back to the **rule-based verdict only**
(`critic-service.ts`): `pass` when no deterministic rule flag fired, `confidence: 'low'`,
`rationale: null`. So a degraded run produces a wall of `pass` that *looks* like an adversarial
all-clear but had **zero LLM scrutiny**.

Critically, the v2 entry gate (`EntryPolicy.filterPick`) accepted any `pass`/`caution` and ignored
`confidence`/`rationale` — so the engine would have entered trades from a 529-degraded brief with no
critic vetting at all. That is **fail-open on AI failure**, backwards for a real-money, fail-closed
engine.

### Fixes
1. **Mark the degradation.** `CriticVerdict.degraded?: boolean` — set `true` in the critic's
   LLM-failure fallback. It's the explicit, unambiguous "the LLM did not run" signal (the success
   path never sets it).
2. **Fail-closed at the gate.** `PickInput.criticDegraded` (mapped in `brief-entry-source.ts` from
   `criticVerdict.degraded`); `EntryPolicy.filterPick` rejects degraded picks with `critic_degraded`
   *before* the verdict check. The engine never trades an un-vetted brief.
3. **Honest UI.** The Daily Brief badge shows **"⚠ Critic unavailable / not vetted"** (neutral
   `critic-badge-degraded` style) instead of a green `✓ Pass`, with an on-expand explanation and the
   "No specific concerns identified" line suppressed when degraded.
4. **Retry harder.** The critic's Anthropic client uses `maxRetries: 4` (SDK default is 2) so a
   transient 429/500/`529` rides out on exponential backoff instead of blanking the critic.

### Validation (FR-SEY-5)
Validation-exempt: the gate change is strictly more conservative — it can only *remove* un-vetted
trades, never add or re-rank vetted ones. Retry + UI are resilience/observability. No scoring,
sizing, or exit logic changed.

### Also surfaced by the audit (not fixed here — inherent to the lean intraday run)
- **Inflection is not tradeable from a 10:15 run.** The partial same-day bar makes `volumeSurge` read
  ~6–7% of average (it's ~45 min into the session), and volumeSurge (w25) + breakoutDecisiveness
  (w30) dominate the inflection composite → it collapses (BALL composite 14.6, 1 pick). Trust
  inflection only from the after-close (~17:00 ET) run with the final bar.
- **Earnings penalty doesn't apply intraday.** `earnings-refresh` is `after_close_only=1`, so the
  lean run skipped it (`earningsFallback: updated 0 / skipped 38 / failed 5`).
- VIX 19.25 looked correct (E*Trade VIX wiring healthy). Bearish empty (likely the ≥70 gate in a
