# v0.23.2 — 2026-06-04

## E*Trade Remote Token Refresh (SSH from phone)

Adds a fully offline-capable OAuth token refresh flow so the E*Trade access token can be renewed from a phone via SSH — no laptop interaction required.

### New: `scripts/etrade-login.mjs`

CLI script that does the full E*Trade OAuth 1.0a flow in a terminal (SSH-friendly):

1. Reads consumer key/secret from the running app's API — or falls back to `~/.tradeanalyzer/etrade-config.json` when the app is offline
2. Fetches a request token from E*Trade and prints the auth URL
3. Prompts for the verifier code (pasted from the phone browser after authorizing)
4. Exchanges verifier for access token
5. **App running:** stores tokens immediately via `POST /api/v1/etrade/token` (encrypted via DPAPI)
6. **App offline:** writes to `~/.tradeanalyzer/etrade-tokens-pending.json`; app imports on next launch

### New: `src/main/api/routes-etrade.ts`

Two new API endpoints under `/api/v1/etrade/`:

- `GET /etrade/credentials` — returns decrypted consumer key/secret (agent token required)
- `POST /etrade/token` — accepts `{ accessToken, accessSecret }`, stores via `secureSet` (DPAPI encrypted)

### Updated: `src/main/api-server.ts`

On every `start()`:

- `writeETradeConfig()` — writes consumer key/secret to `~/.tradeanalyzer/etrade-config.json` (mode 0o600) so the CLI script can run without the app
- `importPendingETradeTokens()` — checks for `~/.tradeanalyzer/etrade-tokens-pending.json`; if present, imports tokens via `secureSet` and deletes the file
