# v0.32.92 — 2026-06-13

## Brief Replay: performance charts modal

A **Charts** button appears in the Brief Replay controls once a run has completed. Clicking it opens a full-screen modal with five analysis tabs.

### Tabs

| Tab | Content |
|-----|---------|
| Performance | Bar charts of avg 21d return and hit rate per strategy + summary table |
| Regime | Grouped bar chart: avg 21d return split by bull/bear SPY regime (50-day SMA gate); per-strategy table with bull/bear n, avg, HR |
| Monthly | Multi-line chart of HR21d over time for all 5 strategies |
| Score Signal | Score quintile → avg 21d return chart (Q1–Q5) + rank-in-brief → avg 21d return chart; warning banner highlighting the anti-predictive scoring pattern |
| Tickers | Per-strategy table of top 4 and worst 3 tickers with ≥4 appearances |

### Implementation

- `BriefReplayService.getChartData()` — new public method. Loads all `replay_outcomes` in one query, computes all aggregations server-side using existing `computeSpyRegimes()`. Bearish strategy HR and sort order are direction-aware (stock down = win). Returns `ReplayChartData | null`.
- `src/main/ipc/ipc-brief-replay.ts` — `replay:get-chart-data` IPC handler.
- `src/preload/index.ts` — `briefReplay.getChartData` bridge.
- `src/shared/types.ts` — `ReplayChartStrategyStats`, `ReplayChartMonthlyRow`, `ReplayChartData` types.
- `src/renderer/src/components/ReplayChartsModal.tsx` — new Recharts-based modal component (600 lines).
- `src/renderer/src/views/BriefReplayView.tsx` — `showCharts`/`chartData` state, `handleCharts` async loader, Charts button, modal render.

### Key insight surfaced

The Score Signal tab visually confirms the anti-predictive scoring pattern discovered in the deep analysis: Q1 (lowest composite scores) consistently outperforms Q5 (highest scores) for buy and bullish strategies. Rank 4 outperforms Rank 1 for buy, bullish, and wheel. This is now visible directly in the app to guide future scoring improvements.
