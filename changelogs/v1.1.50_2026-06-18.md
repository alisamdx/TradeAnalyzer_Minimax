# v1.1.50 — 2026-06-18

## Lower the v2 inflection composite gate 70 → 50 (backtest-validated)

### Context
After v1.1.49 fixed the partial-bar data bug, a follow-up question remained: even with correct data, inflection composites top out around ~55–60 (the all-time max was 62.2) — below the v2 entry gate `min_composite_score = 70`. So the inflection-only engine would still rarely/never enter. The choice was: re-scale the signal normalization, or lower the gate. Per FR-SEY-5 this trade-logic change required a backtest first.

### Backtest
Replicated the exact breakout detection (`computeBreakout`: fresh 20-day high cross, with-trend above SMA50, ATR14, volume-surge) over **5 years of price history — 32,760 with-trend up-breakouts**. Outcome proxy = a bull-put spread with the short strike 5% OTM, "win" = price ≥ short strike after ~30 days (spread expires worthless).

**Results:**
| Entry | Win rate | n |
| --- | --- | --- |
| Random day | 74.9% | 471,971 |
| Any breakout | 75.9% | 32,760 |
| Composite ≥55 (ivRank≈70) | 71.8% | 9.5% of breakouts |
| Composite ≥70 (ivRank≈70) | 69.7% | 2.7% of breakouts |

By signal bucket (anti-predictive):
- `volume_surge`: <0.9 → 77.8% win; 2.0+ → 72.6%.
- `decisiveness`: 0.0–0.2 → 76.4%; 1.5+ → 74.4%.

Signal distributions on real breakouts: `volume_surge` p50=1.10 / p90=2.08 / p95=2.70; `decisiveness` p50=0.34 / p90=1.10 / p95=1.49.

**Conclusions:**
1. Breakouts barely beat a random-day entry (+1%) — the ~76% win rate is mostly market drift.
2. `volume_surge` and `decisiveness` are monotonically **anti-predictive** — higher values → lower win rate.
3. The composite gate is **anti-selective** — the higher the gate, the lower the win rate and the fewer the trades. The ≥70 gate didn't protect quality; it starved the engine.

### Change
- **Migration 052**: `UPDATE exec_config SET min_composite_score = 50 WHERE min_composite_score = 70` — lowers the gate, preserving any user override. Effective for fresh installs (046 seeds 70 → 052 sets 50) and existing DBs.
- A ~50 sanity floor admits genuine breakouts at the base-rate win (~76%) — at worst neutral per FR-SEY-5. Quality control stays with the critic gate (pass/caution) + defined-risk structures + 2× stop / profit target + 1/day, 3/week caps.

### Explicitly NOT changed: normMax scaling
`decisiveness` normMax:3 is technically too harsh (real breakouts top ~1.5 → norm 50), but because the signal is anti-predictive, re-scaling it up would amplify the wrong signal. A miscalibrated-but-non-predictive signal isn't worth "fixing." Left as-is.

### Caveats
- The proxy is **directional** — no credit/IV/stop modeling. It shows the directional signals don't predict the stock holding up; it does **not** claim inflection is unprofitable. The credit/IV economics (the actual edge of vol-selling) need the app's option-priced Backtest engine, which only has forward option data from now.
- Re-validate the gate (and the strategy's net P&L) once live inflection paper trades accumulate.
