# v1.1.72 — 2026-06-24

## Retrospect — Take Profit signal count in the header

### What
The Retrospect header already surfaced `⚠ N Close Signals`. It now also shows a green
`✓ N Take Profits` chip next to it, so both actionable states are visible at a glance.

### How
`RetrospectView` computes `takeProfitCount = openPositions.filter(p => p.insight.action === 'take_profit')`
— the same `insight.action` the In Progress grid's Action column renders, so the badge and the grid
agree. (The existing Close Signal badge counts `recommendation === 'close_signal'`, which is
equivalent to `insight.action === 'close'`, so the two badges are consistent.) The chip renders only
when the count is > 0, mirroring the Close Signal badge. New `.retro-profit-badge` style (green
variant of `.retro-alert-badge`).

Presentation-only — no data, logic, or schema change.
