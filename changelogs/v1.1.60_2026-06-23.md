# v1.1.60 — 2026-06-23

## Trading Desk redesign (spec 08 §5, Part D)

The final piece of the unattended-paper-operation feature (Parts A–C shipped in v1.1.58–59). The
Trading Desk goes from a single long scroll to a **tabbed** surface so each grid stays large enough
for many rows, with a proper stylesheet, **aligned headers**, and **click-to-sort** everywhere.

### Always-visible header (above the tabs)
Unchanged from v1.1.58 — PAPER/LIVE badge + engine-state pill, the **arm switch** (Off / Dry-run /
⚡ Armed) with the **paper-only guard prominent**, Start/Pause/Stop, Kill Switch, capital-deployed
gauge, day P&L, broker/health status.

### Tabs (§5.3)
| # | Tab | Content |
|---|---|---|
| 1 | **Live** | Default landing. Daily **activity timeline** (§5.5) + friendly live activity feed. |
| 2 | **Proposals** | Sortable grid; badge + ⚠ **only when approval is needed**; **auto-focuses** on a new pending proposal. |
| 3 | **Entries** | Today's entries (positions opened today) **+ dry-run "not placed"** rows. |
| 4 | **Exits** | Today's exits (positions closed today) **+ dry-run exits**, tagged **protective / discretionary**. |
| 5 | **Rejects** | Today's gate/proposal/order rejections + gate reason. |
| 6 | **Positions** | All open positions. |
| 7 | **Activity** | Full audit trail. |

Each tab badges its row count. Every grid is click-to-sort via the shared `useSortable` hook.

### Daily activity timeline (§5.5)
A horizontal "story of the day" at the top of the Live tab: **9:30 open / 4:00 close** markers, a
shaded **entry window**, and **pinned events** (brief committed · entries · exits · kill trip/clear)
positioned by their ET wall-clock minute. Hover shows the time + label.

### Live activity feed
Today's audit events rendered as readable one-liners with color-coded dots (entered AMAT ×2 · exit
fired (profit_target) · gate rejected XYZ — per-ticker cap · kill switch tripped …), newest first.

### Derivation (per ET day, renderer-side)
- **Entries** = `getRecentPositions` rows with `opened_at` ET-date == today, plus `exec_dry_run_log`
  entry rows for today (marked "dry-run · not placed").
- **Exits** = recent positions with `closed_at` ET-date == today (close reason → protective/
  discretionary), plus dry-run exit rows.
- **Rejects** = today's audit rows in {`gate_reject`, `proposal_rejected`, `order_rejected`,
  `proposal_user_rejected`} with the parsed reason.

### Backend
- New `ExecutionEngine.getRecentPositions(limit)` (open + recently-closed, newest-activity-first) —
  needed because `getPositions` is open-only. IPC `execution:get-recent-positions` + preload
  `window.api.execution.getRecentPositions`. `getPositions` unchanged (Positions tab + count badge).

### Validation (FR-SEY-5)
Validation-exempt: pure presentation. No change to which trades are selected, how they're sized, or
how they exit. This completes spec 08 — Parts A (automation), B (orchestration/freshness gate),
C (lean batch), and D (UI) are all shipped.
