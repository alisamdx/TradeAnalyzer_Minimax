# v1.1.4 — 2026-06-14

## v2 execution subsystem — Phase 3b (control API + SSE)

Completes Phase 3. The Electron control panel's backend: a local HTTP/SSE surface over
the headless engine, reachable when the app window is closed. Still dormant — wired to
nothing yet.

### `control-api.ts` — `ExecutionControlApi`

A Fastify server on `127.0.0.1:7433` (separate from the v1 agent API on `:7432`) wrapping
the `ExecutionCore` + `RiskGovernor`:

- **Auth:** `X-Agent-Token` on every route except the public `/exec/health`, reusing
  `~/.tradeanalyzer/agent.token`.
- **Engine control:** `POST /exec/engine/start` (cold-start reconcile-before-act),
  `/stop` (hard stop), `/pause` (409 if not running), `POST /exec/kill-switch/trip|clear`.
- **Reads:** `GET /exec/state` (engine state + kill switch + mode + health), `/config`,
  `/risk`, `/positions` (non-closed), `/audit?limit=`.
- **Brief-ready handoff:** `POST /exec/brief-ready` — the zero-latency trigger the brief
  job pings (§1.3b); audits and invokes an optional `onBriefReady` hook (Phase 4 wires
  entry-proposal generation here).
- **SSE:** `GET /exec/events` streams the core's events (engine-state / cycle / health /
  reconcile-mismatch); `formatSse` exported and unit-tested.
