# v0.32.52 — 2026-06-09

## Fix: Price Gap Fill doesn't fetch today's close on the same evening

### Root cause
The stale-ticker condition was `MAX(date) < date('now', '-1 day')`. After yesterday's
batch stored e.g. 2026-06-08 as the latest bar, today's run evaluated
`'2026-06-08' < '2026-06-08'` = FALSE → ticker skipped → 6/9 never fetched.

### Fix (`price-gap-fill-job.ts`)
- Universe stale threshold: `< date('now', '-1 day')` → `< date('now')`
- Reference ticker fresh threshold: `>= date('now', '-1 day')` → `>= date('now')`
- Reference tickers that exist but are just missing today now use a `fromDate`
  override (max_date − 3 days, '1M' range) instead of refetching the full 1Y range.
  The 1Y bootstrap range is now reserved only for reference tickers with no history at all.
