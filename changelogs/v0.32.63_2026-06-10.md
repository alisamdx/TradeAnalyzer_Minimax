# v0.32.63 — 2026-06-10

## Fixed

**Portfolio sync: long option legs no longer dropped**

E*Trade sync was filtering out all LONG options (`positionType !== 'SHORT' && quantity >= 0`). For multi-leg strategies like jade lizard / big lizard, the long call hedge was silently discarded, leaving the portfolio screen with fewer positions than actually held.

Changes:
- `etrade-portfolio-service.ts` — `upsertPosition` now maps LONG PUT → `'Long Put'` and LONG CALL → `'Long Call'` instead of returning false.
- `premiumReceived` is null for long options (they pay debit, not collect credit).
- `ipc-portfolio.ts` — Greeks fetch maps `Long Put` to the `put` side of the chain; long positions keep natural (un-negated) Greeks.
- `portfolio-service.ts` — capital calc for Long Put / Long Call uses `entry_price × qty × 100` (debit paid), not `strike × qty × 100`.
- Migration 036 — recreates `positions` table with expanded CHECK constraint (`'CSP' | 'CC' | 'Stock' | 'Long Put' | 'Long Call'`); updates all three views and the trigger accordingly.
- `PortfolioView.tsx` — adds Long Put / Long Call to the manual-add form; fixes CSS class generation (`type-badge long-put` / `type-badge long-call`).
