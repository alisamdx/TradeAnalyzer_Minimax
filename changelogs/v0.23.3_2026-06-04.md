# v0.23.3 — 2026-06-04

## E*Trade OAuth two-step flow (Claude Code on phone compatible)

Splits the interactive `etrade-login.mjs` into two non-interactive scripts so the flow works when run through Claude Code on the phone (no readline TTY required):

- **`scripts/etrade-step1.mjs`** — fetches a request token, prints the E*Trade auth URL, saves OAuth state to `~/.tradeanalyzer/etrade-oauth-state.json`
- **`scripts/etrade-step2.mjs <verifier>`** — reads saved state, exchanges verifier for access token, stores tokens in the running app or pending file

**Phone workflow via Claude Code:**
1. "run etrade step 1" → Claude runs step 1, prints auth URL
2. Open URL in phone browser, authorize, copy verifier
3. "run etrade step 2 with verifier XXXXX" → Claude runs step 2, tokens stored

The original `etrade-login.mjs` is kept for direct SSH terminal use (readline still works there).
