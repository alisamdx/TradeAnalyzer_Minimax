# v1.1.122 — 2026-07-04

## Fixed: Daily Brief Ranked Grid "Best Structure" cell overflow

User report: "The daily brief, Ranked Grid view has Best Structure field that shows Defined Risk Alt and L2-tradeable, the values run over next fields."

### Root cause

The "Best Structure" column of the Ranked Grid table (`BriefGrid` in `DailyBriefView.tsx`) renders three elements per row:

1. The recommended structure link (`.grid-structure-link`)
2. `<DefinedRiskAltLine ... compact />` — the display-only bull-put-spread alternative badge
3. `<Level2DebitAltLine ... compact />` — the display-only L2-tradeable debit-vertical badge

Both alt badges are `<button className="...--compact">` elements containing several inline `<span>`s (tag, structure name, grade, strike, expiry, premium, PoP/risk). They were designed for the card view (`PickCard` → `.pick-detail`), where the surrounding container is a normal block-flow layout and each button naturally starts on its own line.

In the Ranked Grid, the three elements were siblings directly inside a bare `<td>` with no wrapping block container. Combined with `.brief-grid-table { white-space: nowrap; }` and no column width constraint (`table-layout: auto`, no `<colgroup>`), the browser had no reason to break these inline-flex buttons onto separate lines — they rendered side by side, inflating the "Best Structure" column far past its intended width and visually bleeding into the Expiry / Strike / Premium columns to its right.

### The fix

```diff
-              <td>
+              <td className="grid-structure-cell">
                 {row.structure
                   ? <button className="grid-structure-link" ...>
                   ...
                 <DefinedRiskAltLine pick={pick} strategy={strategy} compact />
                 <Level2DebitAltLine pick={pick} strategy={strategy} compact />
               </td>
```

```css
.grid-structure-cell {
  display: flex;
  flex-direction: column;
  align-items: flex-start;
  gap: 3px;
  max-width: 210px;
  white-space: normal;
}
.defined-risk-alt--compact {
  ...
  max-width: 100%;
  white-space: normal;
}
.level2-alt--compact {
  ...
  max-width: 100%;
  white-space: normal;
}
```

The new `.grid-structure-cell` forces the structure link and both alt badges to stack vertically within a bounded 210px column, and `white-space: normal` (overriding the table-wide `nowrap`) lets each badge's own `flex-wrap: wrap` internal spans actually wrap instead of forcing the container wider.
