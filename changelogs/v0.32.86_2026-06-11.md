# v0.32.86 — 2026-06-11

## Fix: composite D&A fallback — netDebtToEbitda was null for 37% of the universe

### The gap

`netDebtToEbitda` was null for 373/1,002 cached tickers. It feeds `leverageQuality`
(wheel), `leverageRisk` (bearish), and the ≤3 criterion in valueScore/growthScore —
where a null is not reweighted but simply fails the criterion, capping stockGrade.

Two distinct causes:
1. **Structural** (banks/energy: JPM, XOM) — no `OperatingIncomeLoss` tagged; EBITDA
   is not meaningful. These stay null by design.
2. **Tag drift** (MSFT, GOOGL, ORCL, many others) — none of the three combined D&A
   concepts we search are tagged anymore. Modern filers tag `Depreciation` (PP&E
   only) and amortization parts separately; the combined cash-flow line often lives
   in a company extension namespace (e.g. `msft:DepreciationAmortizationAndOther`)
   which `facts['us-gaap']` never exposes.

### The fix

New exported `compositeEntries(base, addons)` in `sec-edgar-provider.ts`:
- Periods keyed by exact `start|end|form`; components filed together share period
  dates, so the join is exact and 10-K/10-Q facts never cross-merge.
- Each component list deduped per period first (latest `filed` wins) so comparative
  re-reports can't double-count into the sum.
- A period is emitted only when the base concept (`Depreciation`) has it; addons
  (`AmortizationOfIntangibleAssets`, `FinanceLeaseRightOfUseAssetAmortization`)
  join when present. Base-only is acceptable: understating D&A overstates
  net-debt-to-EBITDA — the conservative direction for a leverage-risk signal.

The synthetic list flows through the existing `annualSeries`/`ttmPair` machinery
unchanged. Selection follows the established most-recent-annual-wins rule: the
composite replaces the combined concept only when its annual series is strictly
more recent (covers "never tagged" and "abandoned years ago" cases).
