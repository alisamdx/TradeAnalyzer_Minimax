# v0.22.24 — 2026-06-03

## Daily IV Capture: overwrite on every run

Removed the "already done today" skip in `DailyIvCaptureJob`. Every run now
processes all universe tickers and overwrites existing rows for today.

`storeReading()` on `IvHistoryService` already uses `ON CONFLICT(ticker, date) DO UPDATE`
so no schema change is needed — the upsert was already there.

### Why
- Running at 11am captured mid-day IV; the 4:30pm scheduled run then skipped all
  tickers and left stale data in `iv_history` for the day.
- Removing the skip ensures the last run of the day always wins, giving EOD IV values
  for IV rank computation.
- Also supports intentional intraday use: run the job at 11am and again at 2pm to
  see how IV rank looks at different points in the trading day.

### Quota
MarketData.app starter plan: 10,000 credits/day. Each run consumes ~1,500 credits
(one call per universe ticker). Up to 6 runs/day before approaching the limit —
well beyond normal usage (2 auto runs + occasional manual runs).
