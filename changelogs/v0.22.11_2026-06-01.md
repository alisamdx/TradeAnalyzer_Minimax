# v0.22.11 — 2026-06-01

## Fix: Strategy Lab scrolling

The Strategy Lab root div had no `overflow-y: auto`, so `.main` (which is
`overflow: hidden`) clipped the strategy list after ~6–8 visible rows. C and F
grades were rendered but unreachable — users could only see the top A+/A/B entries.

**Fix:** added `overflowY: 'auto'`, `height: '100%'`, and `boxSizing: 'border-box'`
to the root div in `StrategyLabView.tsx`. All 31 strategy rows are now scrollable.

- `src/renderer/src/views/StrategyLabView.tsx` — scrollable root container
