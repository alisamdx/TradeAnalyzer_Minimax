# v1.1.23 — 2026-06-15

**Daily Brief accuracy audit (2026-06-16 brief) — correctness batch (no ranking change).**

Deep-dive assessment of the latest brief surfaced a cluster of AI-commentary defects concentrated on the two strategies that matter most for v2 real-money execution — **inflection** (the defined-risk launch strategy) and **bearish**. This release fixes the three pure-correctness issues; the separate `maxLoss`/ranking fix for reverse-lizard structures follows in its own validated release.

## Root cause: a drifted, duplicated constant

The map of "which Strategy Lab structures represent each Brief strategy" existed in **four** independent copies. Three were correct; the **critic's was missing the `inflection` entry**. That single omission cascaded:

- `CriticService.selectRelevantStructure()` returned `null` for every inflection pick.
- The LLM critic context therefore carried **no structure** — and the model said so verbatim (AMD: *"the absence of a `structure` field means no specific trade parameters exist to evaluate"*).
- Structure-aware rule checks (liquidity, grade) silently skipped on the launch strategy.
- The `if (strategy === 'inflection')` direction-selection branch became unreachable dead code.
- Lacking a structure, the critic **invented a straddle** and reasoned backwards: it warned that high IV/IVR made options "severely overpriced for buying," when the real `short-put-vertical` *sells* premium and high IV is *favorable*.

### Fix
- New shared module `src/shared/strategy-structures.ts` exports the one `STRATEGY_RELEVANT_SLUGS` map plus `pickRelevantStructure()`. The critic, brief job, `brief-report-builder`, and `DailyBriefView` all import it — the drift class is now impossible.
- `tests/strategy-structures.test.ts` asserts **every** `ScoringStrategy` is covered (the guarantee the critic lacked) and that an inflection structure resolves.

## Advocate described the wrong trade

The Stage-5 advocate received only ticker/strategy/score/signals — **no structure** — so it inferred the trade type from the strategy name. For inflection it recommended "straddle sells / iron condors / directional calls" (the inverse of the actual bull-put credit spread) and argued high IV was a headwind.

### Fix
The advocate now gets a compact `structure` summary per pick — type, **credit-vs-debit with the IV implication spelled out**, and legs — and is instructed to base the rationale on it and never suggest a different structure. `summarizeRelevantStructure()` in the brief job, sourced from the same shared `pickRelevantStructure()`.

## `counter_trend_itm_strike` false-fired on bearish debit verticals

The rule judged the structure's first `sell` leg. For a `long-put-vertical` (defined-risk **debit** spread), that leg is the lower short put, which correctly sits **below** spot — so the rule labeled a 7–11% **OTM** short put as "at/in the money — zero cushion" (GPN, EL). Both critics spent their entire rationale rebutting the bad flag instead of assessing the trade.

### Fix
The rule now evaluates only the rally-exposed **short call** (inferring side when absent; skipping structures with no short call), and the self-contradictory "(at/in the money)" wording is removed. Regression test added; existing counter-trend tests updated to model the short call explicitly.

## Tests
- `tests/strategy-structures.test.ts` — new (7): coverage parity + selection behavior + inflection regression.
- `tests/critic-service.test.ts` — counter-trend block rewritten to short-call semantics; new long-put-vertical false-positive regression. Full suite: 486 passing.

## Not in this release (tracked separately)
- **Reverse Big Lizard / Reverse Jade Lizard report an unbounded naked-call loss as a tiny bounded `maxLoss`** (e.g. FLUT max loss −$11 / annualized return 100,248%), which also inflates `premiumScore` → grade → bearish ranking. Because it shifts which bearish picks surface, it ships in its own release with a Brief Replay ranking-delta check (FR-SEY-5).
