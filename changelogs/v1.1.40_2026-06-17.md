# v1.1.40 — 2026-06-17

## One-click "Fix" for credit-spread rules in the Payoff visualizer

### The request (user)
The Payoff screen's strategy panel identifies the structure and checks rules (e.g. "credit ≥ ⅓
of spread width"), marking failures with ✗. Add a **Fix** button that adjusts the legs so they
satisfy the strategy's rules.

### The feature
A **🔧 Fix** button now appears in the rules panel header when a credit spread fails the
credit-vs-width rule and a fix is available. It makes the rule pass by **narrowing the protective
wing toward the short strike** — keeping the short/premium leg (the user's chosen strike / thesis)
and moving only the long wing, re-priced from the live option chain at mid. It picks the **widest
strike that passes** (least narrowing), so the change is minimal.

Example (the reported case): a bull put `$620 / $590` ($30 wide, $9.40/sh credit — ✗ vs $10 min)
→ `$620 / $595` ($25 wide, credit ≥ ⅓ of width). The short put stays at $620.

The user chose "narrow the wing, keep my short strike" over "re-pick both strikes from the
canonical template", so the Fix never changes the strike that came from the brief pick.

### Scope & behavior
- Supported: **Bull Put Spread** and **Bear Call Spread** (the two vertical credit spreads — these
  are also the inflection v2-launch structures, and the common failing case). Other strategies'
  rules can't be auto-fixed yet, so the button is simply hidden for them.
- The button only shows when a rule is failing **and** a passing strike exists in the loaded chain
  (it's hidden when the chain isn't loaded — note v1.1.39 now loads the chain for the pick's
  expiry on brief→Payoff navigation, so this works out of the box from a brief pick).
- Re-prices the moved wing at chain mid `(bid+ask)/2`, matching how chain legs are added elsewhere.

### Implementation / tests
- Pure `fixLegsForStrategy(strategyName, legs, contracts)` in `src/shared/payoff-fix.ts` (shared
  module so it's unit-testable under the node project, like `strategy-structures.ts`).
- `tests/payoff-fix.test.ts`: bull-put narrows to the widest passing strike (short kept,
  re-priced at mid); bear-call narrows down; null when chain absent / wing would reach the short
  strike / unsupported strategy. Full suite: **547 passing**.
