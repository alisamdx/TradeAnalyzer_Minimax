# v0.31.2 — 2026-06-07

## Earnings Refresh — proper Batch Job

### What changed
Earnings Refresh is now a first-class batch job registered in the Batch Jobs screen, replacing the silent fire-and-forget `useEffect` added in v0.31.1.

### Behaviour
- **Startup**: runs automatically 60 seconds after launch (gives E*Trade tokens time to load from keychain)
- **24h TTL**: per-ticker cache means most app opens result in all-skips — no API spam
- **Manual**: "Run Now" in Batch Jobs triggers a full refresh with force=false (respects TTL)
- **Progress**: per-ticker live log in Batch Jobs — updated ✓ / cached — / no-data entries
- **Coverage**: open positions + all watchlist items + conviction stocks

### Files
- `src/main/services/jobs/earnings-refresh-job.ts` — new `BatchJobHandler`
- `src/main/index.ts` — register job + extract shared `getEtradeCreds` helper
- `src/renderer/src/App.tsx` — removed silent useEffect (v0.31.1 regression)
