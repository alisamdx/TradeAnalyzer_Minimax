# v1.1.85 — 2026-06-26

## Daily Intelligence Brief — Ranked Grid tab + critic pass-filter

The Daily Intelligence Brief screen gains two view modes and a critic filter.

### Two tabs

- **Grouped** — the existing accordion: expand a strategy, expand a pick for full detail (signals, lab summary, critic rationale, nav row). Unchanged.
- **Ranked Grid** — a new flat, sortable table with one row per pick across **all** strategies, so you can scan the whole day's shortlist ranked top-to-bottom.

Tab selection persists to `localStorage` (`brief-tab`).

### Ranked Grid columns

`Ticker · Price · Conviction · Strategy · Composite · Best Structure · Expiry · Strike · Premium · Rating · Flag · RSI · Actions`

- **Best Structure** is a link → opens the Payoff Visualizer pre-loaded with the recommended structure's legs (same deep-link the card's 📊 Payoff button uses).
- **Actions** are icon buttons: 📊 Payoff · ✓ Validate · 📋 Options · 🔍 Analysis · 🏦 E*Trade — identical navigation to the card nav row (shared `pickNav()` helper).
- All columns are sortable (click the header; click again to flip direction). Nulls always sort last. Default sort: **Conviction** descending.

### Conviction — the cross-strategy ranking

The user asked for a single "top 25, most-recommended → least" list regardless of strategy. Raw **composite** scores can't do this: each strategy scores different signals with different weights, so a wheel 72 and a bearish 71 aren't on the same scale (the code has warned about this in three places for a while).

Two signals **are** comparable across strategies:

1. **Strategy-Lab structure score** (0–100) — every structure is graded on one shared rubric: IV fit + directional alignment + premium quality + liquidity (`strategy-lab-service.ts`).
2. **Critic verdict** — the adversarial LLM review (pass / caution / flag).

**Conviction** blends them:

```
Conviction = labStructureScore(0–100) − criticPenalty
criticPenalty:  pass 0 · caution 15 · flag 35 · not-vetted 25
```

So critic-passed, A-grade structures float to the top and flagged / F-grade ones sink — a defensible "most-recommended first" order.

**Honest framing:** Conviction is a **quality / triage** ranking, **not** a backtested profit forecast. Brief-Replay found the composites weak-to-anti-predictive cross-strategy (we deliberately stopped re-engineering on that sample — see `Requirements/v2-execution/06-seykota-risk-extensions.md`), and the system has no calibrated per-pick expected-return number. The column is labelled "Conviction", and its header tooltip spells out the formula and the caveat. **Composite** stays in the grid as a (non-comparable) reference column with its own warning tooltip.

### Critic pass-filter

A segmented **Critic** control — **All / Pass + Caution / Pass only** — sits in the sub-toolbar and is honoured by **both** tabs:

- **All** — every pick.
- **Pass + Caution** — pass + caution; drops flag and not-vetted.
- **Pass only** — vetted passes only.

Not-vetted picks (no critic verdict, or a degraded/rule-based fallback verdict) are excluded from both pass filters — they were never adversarially reviewed. In the Grouped tab, strategies left with zero matching picks are hidden while a pass-filter is active. Filter selection persists to `localStorage` (`brief-pass-filter`).

### Scope notes

- **RSI** is shown where the strategy's scoring config includes it (buy / bullish / bearish); wheel / income / inflection render `—`. Per the design discussion we kept RSI and dropped Relative Strength, Trend Strength, and Earnings (the last would have needed an earnings join into the brief).
- Ranking + filter logic lives in `src/shared/brief-ranking.ts` (`convictionOf`, `rsiOf`, `passesFilter`) so it's unit-testable in isolation; the view imports it. The card nav row was refactored onto the shared `pickNav()` helper (no behaviour change).
- **Not FR-SEY-5** — this is display/surfacing only; it changes no scoring weight, entry/exit policy, or risk gate, and nothing about which trades the engine takes.
