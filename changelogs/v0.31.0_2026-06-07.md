# v0.31.0 — 2026-06-07

## Earnings Calendar — Full Feature

### New files
- `migrations/034_earnings_calendar.sql` — `earnings_calendar` table (ticker PK, report_date, report_time bmo/amc, source, confirmed flag, cached_at)
- `src/main/services/earnings-service.ts` — fetch, estimate, manual, query
- `src/main/ipc/ipc-earnings.ts` — IPC handlers (get, upcoming, refresh, setManual, delete)
- `src/renderer/src/views/EarningsCalendarView.tsx` — dedicated calendar view

### Data flow
1. E*Trade `GET /v1/market/quote/{ticker}?detailFlag=FUNDAMENTAL` → `Fundamental.nextEarningDate`
2. Fallback: analysis_snapshots `daysToEarnings` field (run_at + daysToEarnings → estimated date)
3. Manual override always available (persisted as source='manual', confirmed=true)
4. 24h cache TTL, skip manual entries on auto-refresh

### Surfaces

**📅 Earnings Calendar view (sidebar)**
- Grouped by date, 90-day window
- Each entry: ticker (→ Analysis), time (BMO/AMC), confirmed/estimated badge, source
- "⟳ Refresh" fetches all portfolio+watchlist+conviction tickers
- "+ Manual" form: ticker + date + time
- "This week" filter

**Validate view — pre-trade warning**
- Amber/red banner when earnings ≤45 DTE from today
- "IV crush risk after report if short options inside DTE window"
- Earnings fetched in background on ticker load + background refresh triggered

**Portfolio view — position badge**
- `📅` badge on open option position rows with upcoming earnings
- `📅!` in red when earnings falls BEFORE position expiry date

**Payoff View — chart annotation**
- Amber strip below P&L chart: "📅 Earnings Jun 18 · 11d" when earnings inside leg DTE
- Red variant when earnings before expiry

**Payoff View — Risk Matrix column**
- Column nearest earnings date highlighted amber: amber header color, 📅 icon, amber left-border on cells
- Works for both real chain columns and synthetic weekly columns
