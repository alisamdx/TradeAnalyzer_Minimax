# v0.22.8 — 2026-06-01

## Daily Technical Signals batch job

Precomputes buy-signal indicators nightly from cached `historical_prices` bars (no live API calls). Results feed the Trade Scoring Engine so the `buySignalScore` signal is available universe-wide without manual Validate-screen runs.

### Architecture

```
DailyTechnicalSignalsJob (16:30 chain, after price-gap-fill)
  → reads historical_prices for all tickers with ≥26 bars
  → computes per ticker: SMA20/50/200, RSI, MACD (12/26/9), Bollinger Bands,
    candlestick patterns, demand zone proximity, trend label
  → derives buySignalScore (0–100, mirrors Validate screen logic)
  → upserts to technical_signals table (one row per ticker)
```

### Buy signal score formula (Phase 1)

| Component | Max pts |
|---|---|
| MACD bullish crossover (last 5 bars) | 20 |
| MACD above zero (if no crossover) | 10 |
| RSI: oversold recovery (<30→recovered) | 20 |
| RSI: healthy zone (35–65) | 10 |
| Bollinger: price near/below lower band (<15%) | 15 |
| Bollinger: price in lower zone (<30%) | 8 |
| Strong bullish pattern (engulfing, morning star, 3WS) | 20 |
| Moderate bullish pattern (hammer, doji, piercing) | 12 |
| Price at demand zone (≤2%) | 15 |
| Price near demand zone (≤5%) | 8 |
| Bullish trend (price>SMA50>SMA200) | 15 |
| Sideways trend | 5 |
| Bullish SMA structure (SMA50>SMA200, not full bullish) | 10 |
| Testing SMA50 support (within 5%) | 8 |
| **Max** | **100** |

Strong ≥ 50, Moderate ≥ 25, None < 25.
