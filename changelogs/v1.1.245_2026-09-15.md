# v1.1.245 — 2026-09-15

## Day diagnostics, delisted tickers removed, short interest verified

### Why

The 2026-09-14 gate email (`[TA-Data] 2026-09-14 after_close — …`) never arrived. The evidence that was readable showed the collector ran every phase: archive files for every domain between 17:59 and 18:49 ET, and a clean host close at 18:56:49. Both brief runs and all their emails logged clean, and the 19:30 watchdog stays silent by design when a run completed.

The one record of whether the gate email was sent is `qa_quality_report.email_status` / `email_error`, plus the data-collector run's note ("email sent" / "NOT sent (…)"). Both live in databases that can only be read safely from inside the app. The collector's `sendEmail` wrote no log line. **The cause is not known yet.** This release makes it readable.

### Changes

1. **Batch run log.** `BatchService` takes an optional run logger. `index.ts` writes every finished run to `logs/errors` as `batch-run:<jobId>` with status, duration, trigger, slot, counts, note and error. It covers `runJob` and `runJobDirect` (orchestrator sub-jobs), and cancelled runs too. A throwing logger never breaks a run.
2. **Collector email outcomes.** The host's `sendEmail` logs `collector-email:sent` or `collector-email:failed` (with the SMTP message) and rethrows, so core still records the failure in `qa_quality_report`.
3. **`GET /api/v1/diagnostics/day?date=`** (`routes-diagnostics.ts`, `services/day-diagnostics.ts`):
   - batch runs for the ET date
   - errors-log entries
   - API-log summary (calls per provider and per ET hour, failure groups keyed by provider, status, path and the provider's own message, with symbols)
   - the TA2 generation: `meta_run`, `qa_quality_report` with parsed domains, the latest `qa_domain_day_status` per domain, `meta_response` counts and failures, `qa_exception` counts
   - an attention list

   Each generation section fails on its own. The generation is not opened while `data-collector`, `collector-oneshot` or `collector-watchdog` holds the mutex.
4. **`scripts/day-report.mjs`**: Markdown report from the route, saved to `~/.tradeanalyzer/day-reports/`.
5. **Migration 085 `constituents_excluded`**: seeds AVB, EA, EQR, LBRDA, LBRDK and WBS with their delisting reasons, then deletes them from `constituents`. `ConstituentsService.getExcludedTickers()` is applied in `applyRefresh`, `bootstrapFromBundled` and `importFromCsv`.
6. **Short interest verified (core 0.6.9)**:
   - `verify` removed from `raw_short_interest.short_interest`
   - the `chain subset is empty` skip removed from `runShortInterest`
   - dictionary description and ingest comments updated

### After installing

- `node scripts/day-report.mjs --date 2026-09-14` shows the gate report's `email_status` and `email_error` and the data-collector note. That is the answer to the missing email.
- TA2 → Jobs → queue `universe_seed`, then TA Batch → run Collector one-shot. This closes the six tickers' universe membership in gen-002.
