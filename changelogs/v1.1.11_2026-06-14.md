# v1.1.11 — 2026-06-14

## Fixed — scrollable sidebar

The left navigation menu now scrolls when it's taller than the window, instead of clipping
the bottom items.

### Cause

All nav buttons render inside a single `.nav-section` div within `aside.sidebar`. The
sidebar is `display: flex; flex-direction: column; overflow: hidden`, but `.nav-section`
had no flex sizing and no overflow rule — so once the menu (now 9 sections, incl. the new
🤝 Execution group) exceeded the viewport height, the overflow was simply clipped and the
last items (Misc → History) became unreachable on shorter windows.

### Fix (`src/renderer/src/styles.css`)

`.nav-section` now fills the sidebar and scrolls:

```css
flex: 1;
min-height: 0;     /* lets the flex child shrink below content height */
overflow-y: auto;
```

`min-height: 0` is the key — without it a flex item won't shrink past its content size, so
the sidebar's `overflow: hidden` would keep clipping instead of letting `.nav-section`
scroll. Uses the default OS scrollbar to match the app's other scroll areas
(`.items`, `.sidebar ul`).

No automated test — this is a visual layout fix with no unit to assert.
