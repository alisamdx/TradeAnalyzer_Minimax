# v1.1.77 — 2026-06-25

## "Open in Lab →" from the Pre-Trade Validator suggestion

Closes the loop from the validator's "here's a better structure" to actually exploring it.

When the Pre-Trade Validator (Payoff view, v1.1.76) flags a trade and the Strategy Lab suggests
a better structure, a small **Open in Lab →** button now sits next to the **LAB SUGGESTS INSTEAD**
header. Clicking it:

1. Navigates to the Strategy Lab (`navigate-to-strategyLab` deep-link, now with an optional `slug`).
2. Lands on the **Explore** tab pre-populated with the suggestion's **ticker + structure**.
3. **Auto-builds** the concrete setup once on arrival (a single `explore` call) so the details
   show immediately — no manual "Run" click.

### Plumbing
- `PayoffView` suggestion block: header is now a flex row with the label + the button (shown only
  when a ticker is set). Dispatches `navigate-to-strategyLab` with `{ ticker, slug }`.
- `App.tsx`: `navigate-to-strategyLab` detail gains optional `slug`; nav entry carries
  `strategyLabSlug`; passed to `StrategyLabShellView`.
- `StrategyLabShellView` → `StrategyLabView` thread `initialSlug`. With a slug present the lab
  defaults to the **Explore** tab and seeds `exploreSlug`.
- `ExploreTab` gains `initialTicker` (used when there's no full lab context to derive it from)
  and a one-shot `useRef`-guarded effect that auto-runs `explore` when it mounts pre-populated.

Renderer-only navigation wiring — no service/logic change, so the test suite is unaffected
(728 passing); typecheck clean.
