# v1.1.124 — 2026-07-07

## Retrospect "In Progress" tab: "Close All" for Close Signal / Take Profit badges

User request: the header of the Retrospect screen shows counts like "⚠ 104 Close Signals" and
"✓ 28 Take Profits" — but the In Progress tab only ever displays one brief date at a time (via
a date dropdown), so acting on those flags meant switching through every brief date and closing
positions one by one.

### What shipped

Each badge now has an adjacent **Close All** button. Clicking it:

1. Filters `openPositions` (already loaded for the whole tab, not date-scoped) by the matching
   flag — `recommendation === 'close_signal'` for the Close Signal badge, `insight.action ===
   'take_profit'` for the Take Profit badge.
2. Shows a confirm dialog with the exact count before doing anything.
3. Calls the new bulk-close IPC, then reloads the open-positions list (and closed-trades list
   if the History tab happens to be active).

### Backend: `PaperTradingService.closePositions(ids, notes)`

Refactored the existing single-position `closePosition()` to share its row-level close logic
(`closeOneRow`) with a new bulk method:

- DB updates for all ids run inside one `withTransaction` — same exit-price auto-fill from
  `historical_prices` and same structure-P&L computation as an individual Close click.
- The existing fire-and-forget AI learning-capture call (`captureCloseLearning`, one Claude
  Haiku call per closed trade) is **not** parallelized for the bulk path — it awaits one at a
  time in a background loop, so closing 100+ positions doesn't burst 100+ concurrent requests
  at the configured Anthropic key. Non-fatal either way (existing try/catch).
- Skips ids that are missing or already non-open, same as the single-close guard.

New IPC `paper:close-bulk` (`ipc-paper-trading.ts`), new preload `window.api.paper.closeBulk(ids,
notes?)` (`src/preload/index.ts`) — `window.api` types pick it up automatically since
`global.d.ts` derives from the preload's exported `Api` type.

### UI

`src/renderer/src/views/RetrospectView.tsx`: new `handleCloseAll(filter, label)` helper; badges
wrapped in `.retro-alert-badge-group` with a `.retro-close-all-btn` (`src/renderer/src/styles.css`).
Bulk-close notes are tagged `"Bulk close — Close Signals"` / `"Bulk close — Take Profits"` so
`exit_notes` stays traceable to a bulk action vs an individual close.

### Tests

`tests/paper-trading-close-bulk.test.ts` (new, 2 tests): bulk-closes only the still-open ids in
a requested list (skips an already-closed one, doesn't double-close), and is a no-op on an
empty list. Full suite: 917 passed, 1 skipped.
