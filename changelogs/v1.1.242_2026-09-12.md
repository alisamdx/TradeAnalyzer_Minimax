Existing app only. NewApp TODO **#37**; design `NewApp/requirements/07-opportunity-engine.md` §3.

## What

**🎯 Wheel Shortlist** — after every brief run (and on demand from the Daily Brief), the top 5
cash-secured puts at the operator's profile, priced live, ranked by premium return on capital.

## Operator decisions it implements (2026-09-12)

| | |
|---|---|
| Objective | premium return on capital, avoid assignment |
| Profile | 0.35–0.45Δ, 14–30 DTE |
| Roll rule | ITM with ≤ 7 days left → next 14–30 DTE expiry, same/lower strike, net credit; else close |
| Output | top 5, no capital cap |
| Cadence | after both brief runs |

## Mechanics

- `src/main/services/wheel-shortlist.ts` — `computeWheelShortlist({ db, provider, now })`:
  pool from the latest `brief_candidates` run (wheel + income, `picked`/`capped_out`, deduped);
  critic verdicts from the latest wheel/income `daily_briefs` (flag excludes); earnings fail-closed;
  expirations → in-window expiries before the next report → chains → `pickShortlistContract`;
  `pickRollExpiration` (nearest expiry 7–30 days after) → `computeRollRoom`; own-at-strike via the
  now-shared `loadPriceWindows`. Every exclusion is a reported reason; flagged/stale names spend no
  E\*Trade call.
- `src/shared/wheel-shortlist.ts` — `SHORTLIST_PROFILE` and result types, shared by main, preload, renderer.
- `src/main/services/shortlist-email-builder.ts` — null-safe card list; the top idea in the subject.
- `src/main/services/brief-emails.ts` — `deliver()` generalizes compute/build/send/retry/log;
  `sendDiceEmail` rebuilt on it (behaviour and log operations unchanged), `sendShortlistEmail` added.
- Brief job: `sendShortlistEmail` after the dice email, inside the email-configured block.
- IPC `scoring:wheel-shortlist`, `scoring:email-wheel-shortlist` (`registerScoringIpc` now takes the
  options provider); preload `scoring.wheelShortlist` / `emailWheelShortlist`; Daily Brief button + panel.

were measured at 0.20–0.35Δ / 30–45 DTE (v1.1.171, v1.1.176). The profile's own evidence — including
