# v0.22.22 — 2026-06-03

## Test API: MarketData.app live chain support

### Problem
The MarketData.app tab in Test API was passing `?date=YYYY-MM-DD` for all queries.
MarketData.app treats `date` as a historical expiration filter only — passing today's
or recent dates returned `400: "Invalid date. The date parameter is used for historical queries only."`.

### Changes

**`src/main/services/marketdata-provider.ts`**
- `getLiveChain(ticker, expiration)` — fetches today's live chain using `?expiration=` param
- `getRawLiveChain(ticker, expiration)` — raw unparsed live chain for Test API diagnostics
- `nearestMonthlyExpFor30Dte()` — exported helper; returns the nearest 3rd-Friday monthly
  expiration between 20–45 DTE (or closest to 30 DTE overall). Used to auto-select the
  target expiration for the daily IV capture path.

**`src/main/ipc/ipc-test-api.ts`**
- `test-api:get-marketdata-live-chain` handler — takes a ticker, auto-selects the best
  expiration via `nearestMonthlyExpFor30Dte()`, runs `getLiveChain`, computes ATM IV,
  returns full `MarketDataTestResult` diagnostics.

**`src/preload/index.ts`**
- `window.api.testApi.getMarketDataLiveChain(ticker)` bridge added.

**`src/renderer/src/views/TestApiView.tsx`**
- MarketData.app tab now has a **Live (today) / Historical** mode toggle.
- Live mode: no date input, auto-computed expiration, calls `getMarketDataLiveChain`.
- Historical mode: unchanged (as-of date input, `getChainForDate` two-call path).

### Why this matters
This is the validation step before switching `DailyIvCaptureJob` from E*Trade to
MarketData.app. E*Trade OAuth tokens expire at midnight ET — the daily IV job cannot
run unattended. MarketData.app uses a static API key ($12/month starter plan).
The live chain test confirms whether real IV values are returned (vs null / Black-Scholes
fallback) before any production job change is made.
