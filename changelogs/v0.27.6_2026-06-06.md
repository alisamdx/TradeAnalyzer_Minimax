# v0.27.6 — 2026-06-06

## Retrospect Summary — Next-Day Accuracy section

The Summary tab now shows a **Next-Day Accuracy** section powered by the new `paper_trade_snapshots` table.

### What's shown

**By Strategy table** — for each of the 5 strategies:
- Picks snapshotted, Positive / Negative / Neutral counts
- Accuracy % with the same win-rate bar as the existing breakdown (hidden until ≥ 3 picks)
- Average next-day return %

**Brief Accuracy Trend table** — one row per brief date (newest first):
- Picks, Positive / Negative counts, Accuracy %, Avg Return

Both tables use the **first trading-day close after the brief** as the evaluation point — not "today's price" — so every brief is measured on equal footing regardless of how long ago it ran.

### When data appears

The `Daily Paper Trade Snapshot` job runs at 17:00 ET. Until it runs for the first time, a placeholder message explains what to expect.
