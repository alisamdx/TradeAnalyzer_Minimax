# v0.32.37 — 2026-06-08

## AI Critic: four context enrichment improvements

All changes are in `critic-service.ts` (`synthesizeVerdict`) and `routes-critic.ts`.

### 1. DTE pre-computed (`structure.dte`)
Previously the LLM had to subtract `marketData.date` from `structure.expiry` itself. This produced errors — e.g. "July 2026 = 12-month hold" when today is June 2026. Now `dte` is computed server-side before the context is serialised.

### 2. Market context (`marketContext`)
`getMarketContext()` was already called for rule checks but the data was silently dropped before the LLM call. Now `vix`, `vixLevel` (low/normal/high with thresholds), and `spyTrend` (bullish/bearish with MA label) are passed in context. The model can calibrate income/wheel recommendations against current fear regime and trend regime without recalling from training.

### 3. Earnings in hold window (`earningsInWindow`)
New `getEarningsBeforeExpiry(ticker, expiryDate, today)` queries `earnings_calendar` for any event between today and the structure's expiry. Returns `{ date, daysFromNow, confirmed }` or `null`. This is the single biggest event risk for any options position and was previously invisible to the LLM.

### 4. Pre-computed risk metrics (`strikeOtmPct`, `breakevenDistancePct`)
- `strikeOtmPct`: `(price - strike) / price × 100` — positive = OTM, negative = ITM; computed for all strategies with a short strike
- `breakevenDistancePct`: income only — `|credit| / price × 100` — how far price can move before the structure loses; replaces the LLM doing this arithmetic itself (which it was getting wrong)

### Caller changes
- `daily-intelligence-brief-job.ts`: passes `marketContext` to `synthesizeVerdict`
- `routes-critic.ts` (TraderAgent API): same fix
