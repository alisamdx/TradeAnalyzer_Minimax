# v0.22.6 — 2026-06-01

## Batch Jobs — sequence order moved to Edit modal

Removed the ▲/▼ buttons from the jobs table. The `#` column is now a read-only display of `sequenceOrder`. To change a job's position, open its Edit modal and set the **Sequence order** number field (min 1). Jobs are sorted ascending by `sequence_order` in both the UI and the scheduler.

### Files changed

- `src/main/services/batch-service.ts` — `updateJobConfig` now handles `sequenceOrder` patch
- `src/renderer/src/views/BatchView.tsx` — `handleMove` removed; ▲/▼ buttons replaced by plain `sequenceOrder` cell; `sequenceOrder` input added to `EditModal`
