# v1.1.362 — 2026-10-14

## QC-413 counts the host's real E\*Trade renews (`core` 0.6.75, `next` 0.4.60, dictionary v25)

The pilot-exit review of never-fired checks on 2026-10-14 found that QC-413 (renew storm) could not fire, and ruled it "fix".

**Why it could not fire.** QC-413 counted `meta_response` rows whose endpoint matched `renew_access_token`. The collector never makes that call itself. `ElectronCollectorHost.etradeGet` renews through this app's own E\*Trade transport (`renewAccessToken` in `etrade-auth.ts`) and hands `core` only the market response. So no renew was ever captured. On the 2026-10-14 gen-002 snapshot `meta_response` held zero renew or OAuth rows across every run, and QC-413 read 0 every night, whatever happened.

**What changed**
- **`CollectorHost.etradeRenewAttempts?()`** (optional). It returns how many renews the host has attempted since it was built, successful or not. `ElectronCollectorHost` increments its counter just before each `renewAccessToken` call, so a renew that throws is counted too. It is a number only. No token value, secret or response body is kept or stored.
- **`meta_run.etrade_renew_count`** (new nullable INTEGER, dictionary v25, additive). `runDaily` reads the host's count before preflight (whose SPY probe can renew) and again just before the gate, and writes the difference with `recordRenewCount`. The write adds to any existing value, so a resumed run keeps what its earlier attempt recorded. A failed write goes into the phase errors and never stops the run.
- **QC-413** now reads that column. The threshold is unchanged: it fires above 20 renews in one run. A NULL count (a host that does not report renews, or any run before v1.1.362) evaluates nothing. It is never read as a measured zero. Because the count is in the generation, `rehearse-gate.mjs` sees it on snapshots of new runs.

**Expected noise.** The token latch stops all E\*Trade calls after a renew comes back expired, and the keep-alive heartbeat keeps the token active through the evening run. So a normal run should renew a handful of times at most. Older runs stay unmeasured, so tonight's run is the first real value.
