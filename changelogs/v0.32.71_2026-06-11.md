# v0.32.71 — 2026-06-11

## Batch Orchestrator

### What changed
Introduced a `BatchOrchestratorJob` that replaces the need to run individual jobs on their own schedules. It is the **only** job with a schedule; all other jobs have their schedules managed by the orchestrator.

### How it works
1. **Non-trading day guard** — scheduled runs skip immediately with a clear message; manual/API runs proceed (individual jobs still self-skip via their own guards).
2. **E*Trade token renewal** — calls `renewAccessToken()` before any jobs run; aborts if invalid.
3. **Start email** — one consolidated email at start time: token status, resume state (fresh vs step N/10), outcome (started / failed to start).
4. **Job loop** — runs sub-jobs in `sequence_order`; skips any with `last_success_date = today`; stops at first failure.
5. **Natural resume** — re-triggering the orchestrator on the same day skips already-succeeded jobs and picks up from the failure point.
6. **Multi-slot scheduling** — `config_json.scheduleSlots` holds an array of `'HH:MM'` ET times; each slot fires at most once per day (tracked in `batch_runs.slot_time`).

### Remote trigger (Termius / Claude Code CLI)
```bash
# Trigger
curl -s -X POST http://127.0.0.1:7432/api/v1/orchestrator/run \
  -H "X-Agent-Token: $(cat ~/.tradeanalyzer/agent.token)"

# Status
curl -s http://127.0.0.1:7432/api/v1/orchestrator/status \
  -H "X-Agent-Token: $(cat ~/.tradeanalyzer/agent.token)"
```

### UI changes
- Orchestrator row appears at the top of the Batch Jobs list (⚙ prefix, blue highlight).
- Clicking ✎ Edit on the orchestrator opens a custom modal: job enable/disable list + `validateEtradeToken` / `emailOnStart` toggles.
- "Run All in Sequence" button excludes the orchestrator.
- Run history table has a new **Trigger** column (`manual`, `sched HH:MM`, `startup`).

### Migration 037
- All `batch_jobs.sequence_order` shifted +1 (orchestrator inserts at 1).
- `batch_runs.trigger TEXT NOT NULL DEFAULT 'manual'` — how the run was initiated.
- `batch_runs.slot_time TEXT` — which scheduler slot fired it (null for manual/startup).
